## Slice 078-02 — gate-stats digest

**Goal:** Print a read-only, per-gate bypass histogram over a `--days N`
window (aggregated from 078-01's events) — an **override-frequency audit
trail** answering the spec Overview's question "how often is each gate
bypassed?" (EngTip #19). Counts are bypasses only (no denominator of
respected fires), so the digest is deliberately **not** a "gate is
deadweight" verdict (see the refinement-todo denominator entry).

**DoR:**
- ✅ 078-01 DONE — bypass events are being written to the sink.

**Acceptance Criteria:**

1. **Per-gate counts.** A read-only command (extend `routing-stats` or a
   sibling `gate-stats`) prints, per gate, the number of bypasses in the
   window. (Fixture: a sink with mixed events → correct counts.)
2. **Window honored.** `--days N` filters by event timestamp; the default
   matches `routing-stats` (30). (Fixture: events inside/outside the
   window.)
3. **Empty stays exit 0.** No sink / no events prints a zero/empty report
   and exits 0 — read-only, never a finding (mirrors `routing-stats` /
   `stale`). (Fixture: absent sink.)

### Deviation log

**Shipped ahead of slicing (process deviation).** Like 078-01, the digest
landed on `main` in commit `5c31da0` before the lifecycle ceremony; this
record was reconciled retroactively (2026-07-08) by running the full
lifecycle against the shipped code.

**Frame-critique caught a real over-claim (remediated during
reconciliation).** The retroactive frame-critique flagged that the slice
Goal and the shipped `gate_stats` output over-claimed the digest answers "is
this gate deadweight? / is the gate catching anything? / does it earn its
keep?" — a bypass *count* is a numerator with no denominator (respected gate
fires), so it cannot support that keep/retire verdict (a count of 0 is
ambiguous: a golden gate nobody bypasses vs. a gate that never fires). Fixed
by reframing to an **override-frequency audit trail** (matching the spec
Overview + EngTip #19) across five sites: the spec Overview, the spec
Clarifications (gates-in-scope), the spec Decomposition bullet, this slice's
Goal + anti-phasing check + implementation note, and the shipped `gate_stats`
closing message (`skills/spec-workflow/workflow.py` ~2204). The
respected-fire **denominator** was deferred to `docs/refinement-todo.md` with
a resolution trigger. (Two frame-critique rounds were needed — the first fix
missed the spec Overview + Clarifications, caught by re-review.)

**AC1 approach choice.** AC1 allowed "extend `routing-stats` **or** a sibling
`gate-stats`"; the sibling command was chosen (over the non-binding note's
lean to extend), rationale: gate-bypass events are a distinct event type with
bypass-only semantics.
