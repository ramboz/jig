## Slice 078-01 — emit bypass events

**Goal:** Emit one structured, content-free telemetry event whenever the
review-evidence gate or the conventions spec-gate honors its env-var
override — to the existing gitignored local sink, fail-open — so gate
bypasses leave an auditable trail instead of being silent.

**DoR:**
- ✅ The telemetry-sink reuse assumption (spec Assumptions) is
  probe-verified against `jig-telemetry` / `.claude/skill-usage.jsonl`.
- ✅ Event schema agreed (gate name, env var, timestamp, branch/spec-ref).

**Acceptance Criteria:**

1. **Review-evidence gate bypass emits.** When `workflow.py transition`
   advances past a review gate because `JIG_REVIEW_EVIDENCE_GATE=0`, one
   event is appended naming the gate + env var + timestamp + (best-effort)
   spec-ref. (Fixture: transition under the bypass env.)
2. **Conventions spec-gate bypass emits.** When the `jig-spec-gate` hook
   allows an edit because `JIG_CONVENTIONS_APPROVED=1`, one event is
   appended. (Fixture: gated edit under the bypass env.)
3. **No emit on the normal path.** A normal (non-bypassed) transition /
   edit appends nothing. (Fixture: both gates without the override.)
4. **Fail-open + content-free.** A telemetry write failure does not block
   the transition/edit; the event records *that* a gate was bypassed,
   never the diff or the matched secret. (Fixture: unwritable sink → op
   still succeeds, no exception.)
5. **Gitignored, local.** The sink stays working-tree-local and gitignored
   (mirrors `.claude/skill-usage.jsonl`); nothing leaves the machine.

- [x] Reviewed by `reviewer` subagent. Reviewer prompt built by `review.py`.

**Nits carried from review (non-blocking):**
- [corrected] An earlier compliance-review note suggested the review-evidence
  emit could fire *before* the DONE dependency check (a benign over-count on
  dep-check failure). Reconciliation verified the opposite: `_gate_evidence`
  and its `emit_gate_bypass` call run *after* the DONE dependency check (the
  gate's own comment in `workflow.py` states "Runs AFTER the DONE dependency
  check"), so a transition that fails the dep check raises before the emit and
  logs nothing — no over-count occurs.
- [accepted] The review-evidence emit also fires on a transition into a gated
  state whose required-pass set is *empty* (e.g. READY_FOR_REVIEW without
  `frame_review`), recording a "phantom" bypass that slightly inflates the
  078-02 digest. Acceptable — the disable flag was honored on a transition the
  gate owns.
- [deferred] `gate_telemetry.py`'s `project_dir` param is untyped while the
  return type is annotated; annotate `project_dir: str | os.PathLike` next
