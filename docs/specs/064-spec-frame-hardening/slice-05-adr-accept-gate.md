## Slice 064-05 — adr-accept-gate

**Goal:** Enforce OQ2/OQ3 on the **ADR side** — `adr.py accept` gates an ADR's
Proposed→Accepted flip on a passing `frame-critique` verdict (ADRs are always-on
per OQ3), with an ADR-appropriate evidence-artifact home, so a wrong-framed ADR
can't be accepted without an adversarial read at its pre-commitment moment.

> **Split from [064-03](slice-03-frame-critique-pass.md)** (2026-06-07): 064-03
> shipped the frame-critique pass + the spec-side READY_FOR_REVIEW gate. This
> slice adds the ADR-side enforcement, which is a separate subsystem because
> **ADRs aren't slices** — the existing `reviews/slice-NN-*.md` evidence path
> doesn't apply to `docs/decisions/`.

**DoR:**
- ⬜ 064-03 DONE (the `frame-critique` pass + `PASSES` entry + prompt builder
      exist to reuse).
- ✅ OQ2/OQ3 resolved (2026-06-07, ADR-0020 Amendments): ADRs gate at
      `adr.py accept`; ADRs are always-on.

**Acceptance Criteria:**

1. **An ADR-side frame-critique verdict artifact has a defined home** — e.g.
   `docs/decisions/reviews/adr-NNNN-frame-critique.md` — written by a
   `review.py record-review` path that accepts an ADR target (not just a
   spec+slice), reusing the shared `_common/review_evidence.py` frontmatter +
   VERDICT shape. Observable: recording an ADR frame-critique verdict writes the
   file at the defined path.
2. **`adr.py accept` gates on that verdict** — it refuses the Proposed→Accepted
   flip unless a passing (`verdict: pass`) `frame-critique` artifact exists for
   the ADR, naming the missing artifact + the `record-review` command. The gate
   is a **soft / bypassable deliberateness signal** (`JIG_REVIEW_EVIDENCE_GATE=0`,
   per ADR-0011 — mirrors the workflow gate), not hard enforcement.
3. **Default behavior is honest** — because ADRs are always-on (OQ3), the gate
   applies to every ADR accept; the bypass env var is the documented escape for a
   deliberate actor. A clear message tells the author how to produce the verdict
   (build the prompt via `review.py frame-critique <adr-path>`, run a reviewer,
   `record-review`).

### Deviation log (after reconciliation)

The original spec is preserved above. Implementation notes:

- **ADR evidence subsystem (AC1):** `docs/decisions/reviews/adr-NNNN-frame-critique.md`,
  written by `review.py record-review --adr NNNN` (mutually exclusive with the
  spec+slice positionals). Shared schema parameterized in
  `_common/review_evidence.py`: `ADR_REQUIRED_FIELDS` (keys on `adr`, not `slice`),
  `adr_evidence_path`, `validate_adr_evidence`, and
  `parse_verdict_file(path, required_fields=REQUIRED_FIELDS)` (default keeps every
  existing slice caller unaffected).
- **No-drift shared gate-enable:** `_evidence_gate_enabled` + `_GATE_DISABLE_VALUES`
  **moved** to `_common/review_evidence.py` (public `evidence_gate_enabled` /
  `GATE_DISABLE_VALUES`); `workflow.py` re-imports as the `_evidence_gate_enabled`
  alias (byte-identical). Both gates read `JIG_REVIEW_EVIDENCE_GATE` from one source —
  can't diverge (ADR-0002 load-bearing-consistency case; no import cycle).
- **OQ3-vs-grace reconciliation (AC2/AC3):** `adr.py cmd_accept` gates the flip on a
  passing frame-critique verdict **iff** the ADR carries a truthy `frame_review`. New
  ADRs get `frame_review: true` stamped at creation → OQ3 "always-on" holds
  going-forward; a legacy markerless Proposed ADR is **not** gated (the DoD grace
  path). Soft/bypassable; runs before any Status mutation; names the artifact + the
  exact commands.
- **Stamp-location deviation (implementer, correct):** stamped in
  `_render_adr_content` (the shared creation chokepoint the real `reserve_adr` CLI
  routes through), not just `cmd_new` — stamping only `cmd_new` would have left
  CLI-created ADRs unmarked and silently broken always-on.
- **Craft + arch [blocker] (both reviewers) → fixed:** the gate's refusal advertised
  `review.py frame-critique <adr>`, but that subcommand required `## Slice` headings
  and died on any ADR — the prompt-building half was unreachable. Fixed:
  `frame-critique` now detects an ADR-basename target, skips `find_slice_label`, and
  critiques the ADR as its own deliverable; the spec path still requires a slice **and**
  ≥1 deliverable (the relaxed argparse `nargs` re-guarded in dispatch — a regression
  caught by a pre-existing test); the gate message advertises the resolvable
  `docs/decisions/adr-NNNN-*.md` path. Added `FrameCritiqueAdrCliTests`; a focused
  re-review confirmed it end-to-end, no regression. *(The ADR prompt mode extends a
  064-03 surface; it lands here because 064-05's gate depends on it.)*
- **Scope:** `docs/conventions.md` untouched; no stray files committed. CI gate green:
  `run_tests.py` (2462 OK), `spec_lint.py --all`, `validate_manifests.py` (3/3),
  code-health/ruff. No new deferrals; `docs/refinement-todo.md` unchanged.
