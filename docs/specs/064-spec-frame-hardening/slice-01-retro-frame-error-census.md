## Slice 064-01 — retro-frame-error-census

**Goal:** Determine empirically whether bad-frame errors recur in jig's own
spec/ADR history, and whether grounding + adversarial frame-critique would
plausibly have caught them — producing a documented **go/no-go** that gates the
rest of spec 064.

**DoR:**
- ✅ [ADR-0020](../../decisions/adr-0020-spec-frame-hardening.md) filed (Proposed).
- ✅ OQ1 (retro depth: full census vs stratified sample) resolved with the human.

**Question:** Do bad-frame errors (wrong-premise specs/ADRs that propagated and
were caught late, or shipped) occur in jig at a rate that justifies the
frame-hardening machinery — and would grounding/frame-critique plausibly have
caught them early?

**Time-box:** 1 day.

**Acceptance Criteria:**

1. **A documented census exists** (in this slice's Findings, or a linked
   `docs/specs/064-spec-frame-hardening/retro.md`) listing each
   spec/ADR examined and classifying it: *no frame issue* / *frame issue caught
   late* / *frame issue shipped*. Scope per OQ1.
2. **Each identified frame issue is tagged** with whether (a) a probe-first
   grounding requirement and/or (b) an adversarial frame-critique pass would
   *plausibly* have caught it early — with a one-line rationale, not a bare
   yes/no.
3. **A go/no-go recommendation is recorded** in the Outcome block, tied
   explicitly to ADR-0020's kill criterion ("no catchable frame errors → shelve
   the ADR").

**DoD:**
- [x] All ACs pass; census artifact on disk.
- [x] Findings + Outcome blocks filled.
- [x] Reviewed by `reviewer` subagent (read-only; judges the census reasoning,
      not code). Reviewer prompt built by `review.py`.
- [x] Implementation review passed.
- [x] Deviation log produced under this slice heading.
- [x] Reconciliation review passed.
- [x] `docs/refinement-todo.md` updated if any decisions were deferred. (No new
      deferrals — ADR-0020 OQ2–OQ4 already parked; untouched.)

**Findings:** Full census in [retro.md](retro.md). OQ1 resolved with the human
(2026-06-07) as **stratified sample**: 33 distinct artifacts examined (19 ADRs —
all except the driving ADR-0020 — + 14 design-/decision-weighted specs, incl.
both known-instance specs 042/055, the 044 spike, and honest negative controls;
ADR-paired specs counted ADR-side, see retro.md Scope). **4 genuine frame errors
of 33 (~12%)** — 3 caught late (ADR-0008 amendment-on-live-prose; ADR-0011/042
env-var-enforcement; spec 056 nested-transcript misread), 1 shipped-until-fixed
(ADR-0015/051 `HEAD==main`, seeded in 003-03). Catchability: **grounding-by-probe
4/4; adversarial frame-critique 2/4 clean (+2 partial); either 4/4; neither 0.**

Surprises: (1) the lever ranking is **inverted vs ADR-0020's framing** — every
error touches a *runnable surface*, so grounding-by-probe is the load-bearing
half and the critique pass wins cleanly only on the 2 architectural-judgment ADR
cases; (2) jig's existing **"Current state (verified …)" discipline already *is*
grounding-by-probe done by hand** (specs 037/042/044/045) — the proposal's value
is making it mandatory + derived, not net-new; (3) **no "neither-catches" error**
appeared (n=4, small); (4) the corpus is **cleaner than §A1 feared**,
corroborating the user's "haven't noticed this much across ~60 specs." The two
ADR-0020 known instances calibrated correctly (ADR-0011 counts; spec 055 pricing
lived in pre-spec analysis, not the artifact). Three load-bearing census claims
were probe-verified against the repo before recording.

**Outcome:** `spec 064-02 unblocked (go)` — **qualified GO.** ADR-0020's kill
criterion ("no catchable frame errors → shelve") is **not** met (4 catchable
errors, 2 in hard-to-reverse ADRs, one propagating through an implemented sweep
before correction); premise §A1 **weakly confirmed**. The evidence reshapes
*priority within Option B* without expanding scope: **lead with grounding (064-02,
4/4 support); ship the frame-critique pass (064-03) gated / kill-criterion-watched,
not as the headline** — the existing default-off `frame_review` design already
matches this, so no slice rework, only a reconciliation emphasis note.
