## Slice 046-01 - scaffold-doc-command-rendering

**Goal:** Ensure generated scaffold docs contain commands, links, and
skill names that work inside the scaffolded target project.

**DoR:**
- A temp-project scaffold fixture exists or can be created by the test.
- Current broken examples from `workflow.md.template`,
  `architecture.md.template`, and `CLAUDE.md.template` are captured as
  regression fixtures.

**Acceptance Criteria:**

1. **Stocktake command works from the scaffold target.** The generated
   workflow docs point to the copied helper path, and the documented
   command exits successfully in a temporary scaffolded project.
2. **Generated local links resolve.** Scaffolded docs do not contain
   source-tree-only relative links such as `../../skills/...` unless
   those paths exist in the target. A test walks Markdown links in the
   generated core docs and reports missing local targets.
3. **Generated skill names are current.** The scaffold hot cache and
   docs use `/jig:vision-elicitation`, not stale aliases, and do not
   describe landed work as future.
4. **Plugin-root text is install-shape-aware.** `${CLAUDE_PLUGIN_ROOT}`
   appears only where the generated artifact is explicitly documenting
   plugin mode, not as the primary command path for scaffold mode.

### Deviation log (after reconciliation)

The original spec is preserved above. Implementation notes:

- **Defect 1 fixed at runtime, not in the template.** `workflow.md.template`
  was left unchanged — it keeps the `${CLAUDE_PLUGIN_ROOT}/skills/scaffold-init/stocktake.py`
  form so that `--plugin-only` scaffolds (where machinery genuinely lives under
  the plugin root) render the correct path. The in-repo fix is a runtime rewrite
  in `scaffold.py`: `copy_template` gained an optional `post_render` transform,
  and `scaffold()` passes `_rewrite_skill_md_paths` for CLAUDE.md + the `docs/*.md`
  loop **only when `with_machinery`** (`doc_rewrite = _rewrite_skill_md_paths if
  with_machinery else None`). This reuses the exact transform SKILL.md bodies
  already get, so documented and actual paths can't drift.
- **No architecture/ADR impact.** The `copy_template` signature change is an
  optional, backward-compatible param on an internal helper — no module boundary
  or public contract changed, so no `architecture.md` edit and no ADR.
- **Defect 2 (broken link).** `architecture.md.template`'s
  `../../skills/contracts/SKILL.md` relative link (broken even in-source — jig's
  own doc uses single `../`) was reworded to reference `/jig:contracts` by name,
  dropping the fragile file link. Resolves in both install shapes.
- **Defect 3 scope extended by one file.** Beyond the slice's named
  `CLAUDE.md.template`, a second stale `/jig:vision-elicit` + future-tense
  reference was found and fixed in `product-vision.md.template` (in scope per the
  AC3 "generated skill names are current" intent).
- **AC2/AC4 walker scope.** The link/path walkers cover a fixed `_CORE_DOCS` set
  (CLAUDE.md + the four install-facing `docs/*.md`). The seed spec tree
  (`docs/specs/seed/`) is deliberately excluded: it carries only intra-seed
  relative links and is covered by its own greenfield emission path
  (`_emit_seed_spec`). Coverage boundary is intentional, not an oversight.
- **AC1 verifies runnability, not output.** The AC1 test parses the documented
  stocktake command, resolves `${CLAUDE_PROJECT_DIR}`, and executes it asserting
  exit 0 — verifying the rewritten path is *runnable* from the target (the literal
  AC wording). It relies on `stocktake.py`'s exit-0-for-any-directory behavior
  rather than asserting on report content; a future slice wanting stronger
  coverage could assert on the reconciled-slice count.
- **Two craft nits deferred (non-blocking).** The craft pass flagged jig-internal
  spec numbers leaking into adopter-facing templates — `product-vision.md.template`
  ("once 017-04 lands") and `architecture.md.template` ("added by spec 022-02").
  These are the same *class* as AC3 but outside its named probes, and outside
  spec 046's scope (non-goal: "no product copy rewrite"; and 017-04 is DEFERRED,
  so the future-tense is accurate — the issue is the leaked internal number, not
  landed-work-as-future). Logged to `docs/inbox.md`
  (`scaffold/templates/jig-internal-spec-leak`) for a generic future sweep.
- **Review outcome.** Compliance pass: PASS. Craft pass: PASS (no `[blocker]`
  entries; two `[nit]`s above). Full suite green (1464 tests, 3 skipped).
