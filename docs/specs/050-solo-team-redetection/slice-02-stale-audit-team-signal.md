## Slice 050-02 — stale-audit-team-signal

**Goal:** Extend `workflow.py stale` to surface "team signal fires
but `docs/memory/people.md` is absent" as a freshness audit row.
Gives the user a way to discover the team-context drift outside the
`memory-sync` cadence — same shape as the existing `last_verified`
drift surfacing.

**DoR:**
- ✅ Slice 050-01 in production: team-signal re-check helper exists
  and is importable from `workflow.py`.
- ✅ `workflow.py stale` exists and emits a structured list of
  findings (slice 015-03).

**Acceptance Criteria:**

1. **`stale` includes team-signal finding.** When the project's
   team signal fires AND `docs/memory/people.md` is absent AND
   `.jig/no-people-md` is absent, `stale` emits a finding row:
   `team-signal: project has N contributors but people.md is
   absent. Run /jig:memory-sync to bootstrap.`
2. **Read-only.** The finding does not auto-bootstrap or mutate
   any files. Same posture as the rest of `stale`.
3. **Opt-out respected.** When `.jig/no-people-md` is present, the
   finding is suppressed. Parity with slice 050-01.
4. **Exit code unchanged when only this finding fires.** `stale`'s
   exit code semantics (0 = clean, non-zero = findings present)
   apply uniformly. A team-signal-only finding is a real finding;
   exits non-zero.
5. **Distinct finding category.** The row carries a `category:
   team-context` tag so downstream filters (CI, scripts) can
   differentiate it from `last_verified` drift rows.
6. **No double-walk.** The check reuses the team-signal helper's
   cached result if `stale` already ran the detection in the same
   invocation. Avoid redundant `git shortlog` calls.
7. **Tests.** Fixtures cover: team-signal-fires-no-people-md,
   team-signal-fires-people-md-exists (no finding), opt-out-marker
   (no finding), solo-project (no finding), monorepo-parent (no
   finding).

### Deviation log (after reconciliation)

The original spec is preserved above. Implementation notes:

1. **ADR-0002 rule-of-three extraction (the structural part of this slice).**
   `stale` is the **third** skill needing the team-signal logic (scaffold-init,
   memory-sync, spec-workflow), tripping ADR-0002's rule of three (pre-committed
   in slice 050-01's deviation log note 9). The logic moved into a new
   `skills/_common/team_signal.py` as its single home: `TEAM_THRESHOLD = 2`,
   `count_team_contributors`, `team_signal_fires`, the `.jig/no-people-md` marker
   contract (`NO_PEOPLE_MD_RELPATH` / `no_people_md_marker_path` /
   `write_no_people_md_marker`), `people_md_path`, and a composite
   `team_context_drift(target) -> int | None` (N iff signal fires AND people.md
   absent AND marker absent; one git walk per call) shared by both the
   memory-sync nudge and this audit. All three callers were repointed:
   `scaffold.py` re-exports the public names from `_common` (so existing
   callers/tests keep resolving; `detect_team` delegates to `team_signal_fires`,
   and the now-unused `import subprocess` was dropped), `memory.py` imports from
   `_common`, and `workflow.py` imports `team_context_drift`. This goes beyond the
   slice's literal "extend `workflow.py stale`" framing but was anticipated by the
   spec's Implementation note + 050-01 note 9. No new boundary pattern → no ADR,
   no architecture.md change (`_common` is the established shared-helper home).

2. **importlib loader + `load_scaffold=` seam retired (supersedes 050-01
   reconciliation scaffolding).** With the helper now in `_common`, `memory.py`
   imports it directly, so the four-candidate importlib `_load_scaffold_module`
   loader, the `load_scaffold=` test seam, and the obsolete
   `test_team_check_degrades_when_scaffold_unavailable` test (all added during
   050-01's reconciliation to cover an unreachable-scaffold branch) were removed —
   that defensive branch no longer exists. Net simplification.

3. **`--bootstrap` render inlined (deviation #3) + byte-identity now ENFORCED.**
   Retiring the loader removed `_bootstrap_people_md`'s last dependency on
   scaffold's `copy_template`, so the render was inlined as a `{{PROJECT_NAME}}`
   substitution + `atomic_write_text`. For the current single-placeholder
   `templates/docs/memory/people.md.template` this is byte-identical to scaffold's
   path, so slice 050-01's AC5 ("no drift, mirrors scaffold output") still holds.
   Both reviewers flagged that the identity had become an *implicit* invariant of
   template content; reconciliation closed that gap with a cross-check test
   (`BootstrapTemplateParityTests.test_bootstrap_render_matches_scaffold_copy_template_byte_for_byte`)
   that renders the real template through BOTH paths and asserts byte equality
   (verified to fail loudly when a second placeholder is injected) + a comment at
   the render site. The invariant is now enforced, not assumed.

4. **AC4 resolved to intent, not literal (real spec-vs-impl deviation — logged
   per ADR-0010).** AC4 literally says `stale` "exits non-zero" on findings. That
   rests on a false premise: `stale` has *always* exited 0 (the deliberate 015-03
   "informational, never gating" contract; CLI dispatch at `workflow.py` falls
   through to `return 0`), and the literal contradicts this slice's own AC2 ("same
   posture as the rest of `stale`") and Goal 6 ("surface" the drift). AC4's title
   and body intent ("Exit code **unchanged**", "apply **uniformly**") are honored:
   the team-signal finding is surfaced like every other stale row and `stale` stays
   exit-0. Pinned by `test_stale_exits_zero_with_team_finding`. Implementing the
   literal would have been a surprising, higher-blast-radius contract change that
   the spec's own text argues against.

5. **`find_stale_items` row shape `(display, reason)` → `(display, reason,
   category)`.** Existing freshness rows carry `category="last-verified"`
   (behavior unchanged); the new row is `("team-signal", "project has N
   contributors but people.md is absent. Run /jig:memory-sync to bootstrap.",
   "team-context")` (AC1 verbatim; AC5 category tag). The sole unpacker + all test
   consumers were updated; the human-rendered `stale` text is unchanged (category
   is for downstream filters, AC5).

6. **Reviewer findings folded in.** Compliance — `pass`, no blocking issues
   (`reviews/slice-02-compliance.md`). Craft — `pass`, no blockers, two `[nit]`s
   (`reviews/slice-02-craft.md`): (a) the inline-render latent-drift nit → closed
   by the cross-check test + comment in §3 above; (b) a split structured-level
   assertion in `test_finding_carries_team_context_category` → tightened to also
   assert the `/jig:memory-sync` hint in the reason string.

7. **Tests + plan adherence.** New: `_common/test_team_signal.py` (14) +
   `StaleTeamSignalTests` (9) + the parity re-export + bootstrap byte-identity
   cross-check; one obsolete 050-01 test removed. Full suite green:
   `Ran 2182 tests, OK` (3 pre-existing skips); delta across the slice
   2158 → 2182. No decisions deferred → `docs/refinement-todo.md` untouched.
   (Watch-item, not a deferral: the inbox-worthy note that memory-sync's inline
   render and scaffold's `render()` diverge in *guard* behavior — the cross-check
   test is the guard for now.)
