## Slice 054-01 — philosophy-doc

**Goal:** Give a new reader a clean, skimmable "why jig" they can read in two
minutes — a short `docs/philosophy.md` that distills the existing why
(currently a dense README section + a long internal `product-vision.md`) into
bolded theses, named failure modes, and honest objection-handling.

**DoR:**
- ✅ `README.md` "Why jig exists" and `docs/product-vision.md` are available as
  the source content (the substance is already correct — this slice is craft,
  not new positioning).
- ✅ Mysticat's `docs/01-foundations/philosophy.md` is available as the *form*
  reference (lead-with-a-thesis structure, named risks, objection Q&A).

**Acceptance Criteria:**

1. **The doc exists and stands alone.** `docs/philosophy.md` has an H1 and is
   readable start-to-finish without following any link to understand jig's
   why. It carries no forward-broken links (it links only to docs that exist
   today, e.g. `product-vision.md`).
2. **Each section leads with a skimmable thesis.** Every core
   principle/section opens with a **bolded one-line claim** a reader can skim,
   followed by supporting prose — not an undifferentiated wall of bullets.
3. **It names the failure modes jig guards against.** The doc presents jig's
   "scars" (e.g. horizontal drift, invisible scope creep, implementers
   grading their own homework, the context dumb-zone) as named, memorable
   concepts rather than a citation list.
4. **It handles objections honestly.** An objection/Q&A section answers at
   least: "isn't spec discipline just overhead?", "why not a bigger skill
   pack?", and "does the reviewer subagent replace human review?" — with
   answers consistent with `product-vision.md` and `docs/adoption-readiness.md`
   (no contradictory claims; reviewer isolation framed as prompt/tool-scoped,
   not a hard sandbox).
5. **It defers depth to product-vision.** The doc explicitly links
   `product-vision.md` for the full treatment (target users, competitive
   landscape, design principles) and does not duplicate or fork its
   positioning.
