## Slice 054-03 — readme-routing-hub

**Goal:** Slim `README.md` into a routing hub — move internal build-state off
the public front page, tighten the "why" to a skimmable teaser that links the
new philosophy doc, and collapse the two competing getting-started entry
points into one clear path.

**DoR:**
- ✅ Slice 054-01 landed — `docs/philosophy.md` exists for the Why teaser to
  link.
- ✅ Slice 054-02 landed — `docs/prompts.md` exists for the getting-started
  path to link.
- ✅ `CONTRIBUTING.md` exists and is the contributor-facing home for the gap
  map / dogfood ledger.

**Acceptance Criteria:**

1. **README reads as a routing hub.** The top of `README.md` orients a
   first-time reader within roughly one screen: a one-line "what jig is", a
   skimmable Why teaser linking `docs/philosophy.md`, and a single "Start
   here" entry. Reference-depth material (the extension-points deep-dive,
   install-shape caveats) is condensed or linked, not inlined at full length.
2. **Internal build-state is gone from the README.** The gap-response map and
   per-slice / dogfood spec references no longer appear in `README.md`; they
   live in `CONTRIBUTING.md` (contributor-facing), with their owner-spec links
   intact.
3. **One getting-started entry point.** The previously separate "Installation"
   and "Getting started" sections are reconciled into a single path that links
   the cookbook (`docs/prompts.md`) and `docs/adoption-readiness.md`; a reader
   reaches a concrete "say this to Claude" step without first wading through
   four install shapes.
4. **Stale-status guard preserved; gap-map guard retargeted.**
   `scripts/test_readme_status_current.py` still fails if `README.md`
   reintroduces the stale draft-status wording, AND now asserts the
   gap-response map is present in `CONTRIBUTING.md` (≥8 rows, owner-spec links,
   routed-inventory link), AND asserts `README.md` no longer carries the gap
   table. Full suite green.
5. **Supported-today scoping survives.** The honest "supported today vs.
   planned/deferred" distinction (Claude-only today; Codex planned) remains
   discoverable from the public docs (a brief README line and/or
   adoption-readiness), even though the detailed triage moved to CONTRIBUTING.
6. **All README outbound links resolve on disk** (`philosophy.md`,
   `prompts.md`, `adoption-readiness.md` all exist by now).
