## Slice 074-02 - session-plan mode hints

**Goal:** Extend the session-planning surface so each planned phase can carry
an optional advisory host-mode hint without changing `workflow.py` transition
semantics.

**Resolution trigger:** Resume after 074-01 lands and a concrete host adapter
needs machine-readable or generated phase hints, rather than prose-only docs.

**DoR:**
- [x] 074-01 DONE.
- [x] At least one host adapter implementation has a concrete consumer for
      mode hints (`session-plan`, generated primer text, or prompt cookbook).

**Acceptance Criteria:**

1. **Mode hints are advisory.** Any new `session-plan` output clearly labels
   host-mode values as hints, not gates.
2. **Default output stays useful.** Existing `workflow.py session-plan` users
   still see the same phase sequence and subagent/skill routing information,
   with no loss of readability.
3. **Host-neutral enum.** If structured output is added, it uses the portable
   phase vocabulary from 074-01 rather than Claude- or Codex-specific names.
4. **Tests pin no-gate behavior.** Tests prove mode hints do not affect
   transition validation, required review passes, or dependency checks.
