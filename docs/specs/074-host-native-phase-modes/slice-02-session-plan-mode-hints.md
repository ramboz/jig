an optional advisory host-mode hint without changing `workflow.py` transition
semantics.

**Acceptance Criteria:**

1. **Mode hints are advisory.** Any new `session-plan` output clearly labels
   host-mode values as hints, not gates.
2. **Default output stays useful.** Existing `workflow.py session-plan` users
