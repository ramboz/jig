## Slice 074-03 - host-adapter rendering

**Goal:** Render the phase-mode guidance into Claude and Codex host-native
files, preserving one jig workflow model while letting each host use its own
planning / implementation UX.

**Resolution trigger:** Resume when spec 033's Codex scaffold/plugin slices
are actively being implemented, or when Claude scaffold output needs the same
phase-mode guidance.

**DoR:**
- [x] 074-01 DONE.
- [x] 074-02 DONE if structured hints are needed; otherwise an explicit
      decision says prose-only rendering is enough.
- [x] Current Claude and Codex generated-file contracts are re-verified.

**Grounding notes (2026-06-22):**

- Claude scaffold output still renders the host primer to `CLAUDE.md` and the
  detailed workflow guidance to `docs/workflow.md`; verified by
  `GreenfieldScaffoldTests`.
- Codex scaffold output still renders the host primer to `AGENTS.md`, rewrites
  runtime paths to `.codex`, and copies project-local templates; verified by
  `CodexScaffoldAdapterTests`.
- Codex host package output is regenerated from the canonical source by
  `scripts/build_host_packages.py` and verified by the package drift guard.

**Acceptance Criteria:**

1. **Claude rendering.** Claude-facing generated files describe the expected
   plan/implement/review rhythm in host-native terms and keep artifact primacy
   explicit.
2. **Codex rendering.** Codex-facing generated files describe the same rhythm
   using Codex-native terminology and paths.
3. **Shared source, host-native output.** The generated texts are tested so
   the core decision does not drift between hosts, while still allowing
   host-specific wording.
4. **No mode-dependent gates.** Generated hooks, agents, and skills do not
   block or pass based on native mode state.

that host actually reads.

### Deviation log (after reconciliation)

Implementation matched the planned shape; no scope deviations were required.

- Added renderer-owned host phase-mode substitutions so Claude and Codex
  generated files share the same source of truth while rendering host-native
  wording.
- Added lean primer guidance to `CLAUDE.md` / `AGENTS.md` templates and fuller
  advisory guidance to `docs/workflow.md`, explicitly keeping native modes out
  of lifecycle gates.
- Added fixture coverage for Claude and Codex generated outputs, then
  regenerated committed host packages.
- Compliance, craft, and arch reviewers all passed. Craft and arch highlighted
  the renderer-owned substitution pattern and shared-template placeholder as
  strengths because they keep host wording at the adapter boundary without
  forking the workflow model.
