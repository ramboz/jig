## Slice 047-02 - scaffold-contract-validator

**Goal:** Make scaffold verification prove that a generated target has a
coherent local jig install, including copied helpers and generated
settings.

**DoR:**
- Spec 046 has landed or this slice is paired with the fixes from spec
  046.
- A temporary scaffold fixture can run without network access.

**Acceptance Criteria:**

1. **Copied skill helper closure is verified.** Every helper referenced
   by copied scaffold skills exists in the target under the expected
   `.claude/skills/jig-*` path, and stale plugin-root-only paths fail
   verification.
2. **Generated settings are coherent.** `.claude/settings.json` hook
   entries point at copied hook scripts that exist, use the expected
   shell invocation, and match the scaffold install shape.
3. **Generated metadata is checked.** `scaffold.json` includes the
   fields required by scaffold-mode consumers, including the manifest
   version fixed by spec 046, and rejects stale or missing values.
4. **Docs command/link smoke checks are available.** The verifier can be
   run against a scaffolded target and report broken local helper
   commands or missing local Markdown links with path-specific
   diagnostics.
