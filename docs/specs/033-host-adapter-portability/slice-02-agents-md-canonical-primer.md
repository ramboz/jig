## Slice 033-02 - agents-md-canonical-primer

**Goal:** Make `AGENTS.md` the canonical scaffolded project primer while
preserving Claude's `CLAUDE.md` experience.

**DoR:**
- Slice 033-01 is DONE.
- The desired ownership model is confirmed: `AGENTS.md` is canonical;
  `CLAUDE.md` is a Claude adapter surface.

**Acceptance Criteria:**

1. **Template added.** `templates/AGENTS.md.template` exists and carries
   the scaffolded hot cache, key docs, session workflow, and jig-specific
   constraints in host-neutral language.
2. **Claude template narrowed.** `templates/CLAUDE.md.template` becomes
   a Claude-specific adapter that points to or mirrors the canonical
   `AGENTS.md` content without creating an ambiguous second source of
   truth.
3. **Scaffold writes both safely.** `scaffold.py` renders `AGENTS.md`
   and `CLAUDE.md` for Claude scaffold mode, refusing or merging safely
   when a user-owned `AGENTS.md` already exists.
4. **Memory helpers updated.** `memory-sync` knows which primer file is
   canonical for hot-cache writes, and tests prove it does not update
   only `CLAUDE.md` while leaving `AGENTS.md` stale.
5. **Context-fill checks updated.** The context-fill estimator accounts
   for the primer files the host actually loads, avoiding double-count
   assumptions when both `AGENTS.md` and `CLAUDE.md` exist.
6. **Docs and tests use the new names.** Tests and docs that currently
   assume `CLAUDE.md` is the only primer are updated to the canonical
   `AGENTS.md` model or explicitly scoped to Claude.

### Deviation log (after reconciliation)

The original spec is preserved above. Implementation notes:

1. **Canonical primer materialized.** Added `templates/AGENTS.md.template`
   as the host-neutral scaffold primer with Hot Cache, key documents,
   session workflow, sprint focus, and development constraints. Narrowed
   `templates/CLAUDE.md.template` to a Claude Code adapter that imports
   `@AGENTS.md` and carries only Claude-specific scaffold notes.
2. **Primer overwrite safety went slightly broader than the AC wording.**
   The AC only named user-owned `AGENTS.md`, but scaffold now refuses
   user-owned `AGENTS.md` and `CLAUDE.md` unless `--force` is passed. This
   matches `scaffold-init`'s documented "do not overwrite existing primer
   instructions" posture and avoids clobbering legacy Claude projects.
   Jig-managed partial-state recovery still works through the generated
   header watermark, now anchored to the generated quote line near the top
   of the file so prose mentioning "Generated by [jig]" is not treated as
   managed content.
3. **Generated `AGENTS.md` no longer self-triggers Tier 2 signal detection.**
   `AGENTS.md` remains a high-confidence LLM/agent signal for user-owned
   projects, but scaffold ignores jig-watermarked `AGENTS.md` during
   signal detection so crash recovery does not turn jig's own generated
   primer into a false external signal.
4. **Memory helpers use AGENTS-first canonical order with legacy fallback.**
   `memory-sync promote` mutates `AGENTS.md` when present and never creates
   a duplicate Hot Cache in the Claude adapter. Lookups search `AGENTS.md`
   first and legacy `CLAUDE.md` second so pre-033-02 projects still work.
5. **Context-fill and hook checks account for both primer files.**
   The pure estimator now measures `AGENTS.md`, `CLAUDE.md`, and
   `docs/memory/*.md`. Hook-level coverage includes an AGENTS-only warning
   path so the shell integration is pinned, not just the Python estimator.
6. **Docs sweep expanded beyond the minimum deliverables.** Updated the
   scaffold skill docs, memory-sync docs, root `CLAUDE.md`, architecture
   host-adapter boundary, root glossary, product-vision template, brief
   template, spec slice template, and a nearby federation close-out row to
   avoid leaving new canonical-primer users with CLAUDE-only guidance.
   `docs/refinement-todo.md` now records that 033-02 answered the open
   AGENTS/CLAUDE ownership questions; no new deferred decisions were added.
7. **Review results.** Initial compliance, craft, and arch review passes
   all ran. Craft/arch nits were fixed (architecture wording/diagram,
   AGENTS hook integration coverage, generated-AGENTS signal handling,
   command-name typo, context-fill typo). A later compliance pass found
   two blockers (loose watermark false-positive and stale glossary wording);
   both were fixed and the final compliance re-check passed.
8. **Verification.** Final full suite on 2026-05-28: `python3
   scripts/run_tests.py` ran 1387 tests successfully with 3 skipped. Focused
   verification also passed for scaffold-init, memory-sync, slice-land,
   context-fill, hook integration, and `spec_lint.py --slice 033-02`.
