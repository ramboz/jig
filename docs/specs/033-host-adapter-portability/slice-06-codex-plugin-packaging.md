source and host-adapter model.

**DoR:**

**Acceptance Criteria:**

1. **Codex plugin manifest added.** A `.codex-plugin/plugin.json` (or

2. **Bundled assets match scaffold renderer.** Codex plugin packaging
   reuses the same source files and renderer assumptions as Codex
   scaffold mode; there is no second divergent Codex implementation.

   plugin artifacts or explicitly documents how they are produced.
6. **No Claude regression.** Existing Claude plugin and scaffold

   the new Codex option.
