## Slice 072-01 — present-infra-hint

**Goal:** When `land.py prepare` runs against a target that has servo
scaffolded (a `.servo/` directory at the project root), append a soft,
non-gating **servo advisory** section to the readiness report — pointing
at servo's *current* (`/goal`-driven, Routine-triggerable) runtime and, if
a paused run exists at `.servo/runs/<id>/state.json`, naming it as
resumable. Stay completely silent when `.servo/` is absent. Never invoke
servo; never change the exit code.

**DoR:**
- ✅ `land.py prepare` assembles its report from a `parts` list and
  computes `has_blocker` independently of report text — a new section can
  be appended without disturbing the exit code (verified: `prepare()` in
  `skills/slice-land/land.py`).
- ✅ servo's per-project layout is documented: `.servo/install.json`
  (manifest), `.servo/runs/<id>/state.json` (run scoreboard),
  `.servo/triage/inbox.jsonl` (heartbeat inbox) — servo `architecture.md`
  / `ADR-0004` / spec 011.
- ✅ `.jig/`-marker opt-out precedent exists (`.jig/no-people-md`, spec
  050) — reused here as `.jig/no-servo-hint`.

**Acceptance Criteria:**

1. **Advisory appears when `.servo/` is present.** When the resolved
   target root contains a `.servo/` directory (detected by the presence of
   `.servo/install.json` **or** `.servo/oracle.sh`), `prepare`'s stdout
   includes a distinct advisory section (e.g. headed `## servo`) after the
   gating checks. Observable in the report text.
2. **Silent when servo is absent.** When the target root has no `.servo/`
   directory, `prepare`'s output contains **no** advisory section and no
   occurrence of the substring `servo` (case-insensitive) anywhere it
   didn't already appear. This is ADR-0022 §5's "absent → no mention" and
   the supervised-default boundary, asserted directly.
3. **Points at the current artifact shape.** The advisory text names
   servo's post-`ADR-0008` surface — a `/goal`-driven / Routine-triggerable
   loop — and does **not** contain the string "hand-rolled". When at least
   one `.servo/runs/*/state.json` exists, the advisory additionally names
   resuming a paused run (and references the path), so the hint is concrete
   when there is state to resume.
4. **Never gates.** The advisory never adds a `## Blockers` line, never
   changes `prepare`'s return code, and never flips a ready slice's exit
   from 0. A test asserts: same spec/slice, `.servo/` present vs absent →
   **identical exit code**, differing only in the advisory text.
5. **No servo invocation, filesystem-only detection.** `prepare` spawns no
   `servo:*` command, no `claude`, no autonomy primitive; detection is a
   `stat`/`glob` of the target tree only. Asserted by a test that patches
   `subprocess` and confirms detection adds **no** new subprocess calls.
6. **Opt-out honored.** A `.jig/no-servo-hint` file at the target root
   suppresses the advisory entirely (even when `.servo/` is present),
   exactly as `.jig/no-people-md` suppresses the team nudge. Marker
   presence is the only state read; its contents are ignored.

### Deviation log (after reconciliation)

The original spec is preserved above. Implementation notes:

**Shape as built.** Four filesystem-only helpers in `land.py` —
`_servo_present` (`.servo/install.json` OR `.servo/oracle.sh`),
`_servo_hint_opted_out` (`.jig/no-servo-hint`), `_latest_paused_run`
(most-recent `.servo/runs/*/state.json` by `mtime`), and the public
`render_servo_advisory(target)` — appended to `prepare()`'s `parts` list
*after* `has_blocker` is computed (from `checks` alone) and *after* the mode
block, so the never-gating invariant (AC4) is structural, not asserted. The
probe target is `target or Path.cwd()`. 15 tests in `ServoAdvisoryTests`
(`test_land.py`), one per AC plus the DoD edge cases. Full suite green
(2701 tests under py3.13); `ruff` + `spec_lint` clean.

**No material deviations from the planned shape.** Notes folded in from the
two PASS review passes (compliance + craft):

- **`.servo/oracle.sh` signal vs spec.md Assumptions.** AC1 detects via
  `.servo/install.json` OR `.servo/oracle.sh`; the spec's `## Assumptions`
  names only `.servo/install.json` as the durable manifest. The `oracle.sh`
  fallback is within the slice's own AC1 scope — not a deviation — recorded
  here for traceability. (Compliance reviewer.)
- **`_latest_paused_run` returns `None` under a `-> Path` annotation.**
  Deliberate consistency with `land.py`'s existing un-typed-`Optional`
  convention (e.g. `_check_github_remote(cwd: Path = None)`; the module
  imports no `Optional`). Left as-is. (Craft `[nit]`, deferred.)
- **Two servo module constants use different tuple shapes**
  (`_SERVO_PRESENCE_SIGNALS` flat filenames vs `_SERVO_HINT_OPT_OUT`
  positionally-indexed path segments). Cosmetic; left as-is pending any
  repo-wide path-helper convention. (Craft `[nit]`, deferred.)
- **Method-local `import os as _os` / `import time as _time`** in a servo
  test (`test_land.py`) where `os` is already imported module-wide. Trivial;
  left as-is. (Craft `[nit]`, deferred — the craft reviewer rated it "trivial"
  and did not carry it into its own reconciliation notes.)
- **AC5 no-subprocess test** isolates the servo code path by patching
  `subprocess.run` to raise inside `render_servo_advisory` rather than
  diffing a global call count — a faithful (arguably stronger) reading of
  the AC's "detection adds no new subprocess calls." (Both reviewers; not a
  deviation.)

**Environment note (not a slice change).** The repo test suite is not
Python-3.9-clean — `scripts/{verify_install,build_release_zip}.py` and
`test_scaffold_mode.py` use `zip(strict=True)` (3.10+). This reproduces on a
clean tree (confirmed with `land.py` reverted), so it is pre-existing and out
of this slice's scope; jig's CI runs on a newer interpreter. Not parked in
the inbox (jig already uses 3.10+ features in committed code — 3.9 is simply
unsupported).
