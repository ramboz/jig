## Slice 059-04 - codex-skill-override-deferral

**Goal:** Make rendered Codex skill prose honest about richer user skill
overrides and deferral paths.

**DoR:**
- Codex skill rendering from Spec 033 is in place.
- Current Codex skill/plugin docs have been re-checked for user-level or
  plugin-level override semantics.
- Claude override behavior remains the baseline for Claude-rendered docs.

**Acceptance Criteria:**

1. **Claude-only override paths stop leaking into Codex.** Rendered
   Codex skills do not tell users to install richer skills under
   `~/.claude/skills` unless the text is explicitly describing Claude.
2. **Codex override reality is documented.** If Codex has a supported
   user/global skill override path, generated Codex docs name it; if not,
   they say that richer-skill deferral is Claude-specific today.
3. **Shared source remains maintainable.** The solution uses renderer
   rewriting or small host-specific prose blocks rather than forking whole
   skill trees.
4. **Tests cover representative skills.** At minimum, rendered Codex
   `pr-review`, `arch-review`, and `contracts` guidance is checked for
   correct override/deferral language.
5. **Claude docs remain unchanged in meaning.** Claude plugin/scaffold
   outputs still defer to richer user-installed Claude skills as before.
