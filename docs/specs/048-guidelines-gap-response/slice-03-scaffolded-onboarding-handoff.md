## Slice 048-03 - scaffolded-onboarding-handoff

**Goal:** Make a freshly scaffolded project expose the new adoption
guidance without bloating always-loaded prompt context.

**DoR:**
- Slice 048-02 has landed the adoption/readiness guide.
- Spec 046's scaffold artifact fidelity work is either complete or this
  slice explicitly avoids the command/link surfaces that spec 046 owns.

**Acceptance Criteria:**

1. **Scaffold output points to the guide.** The generated project docs
   or hot-cache entry include a compact pointer to the adoption/readiness
   guide or its scaffolded equivalent.
2. **Always-loaded context stays small.** `templates/CLAUDE.md.template`
   receives at most a short link/pointer, not the full guide body.
3. **The guide is reachable in scaffold mode.** If the guide is copied
   into scaffolded projects, links resolve inside the target tree. If it
   is not copied, the generated pointer clearly names the source repo doc
   and does not imply a local file exists.
4. **Scaffold tests cover the handoff.** Existing scaffold fixtures or
   new tests verify the generated pointer, copied-file behavior, and link
   shape for the chosen approach.
5. **No plugin-root leakage.** The handoff text does not require
   `${CLAUDE_PLUGIN_ROOT}` or source-checkout paths in scaffold mode.

### Deviation log (after reconciliation)

The original spec is preserved above. Implementation notes:

- **Deliverables:** new `templates/docs/adoption-readiness.md.template`
  (auto-copied into a target's `docs/` by the existing recursive loop at
  `scaffold.py:1066-1074`) + a one-row pointer in the "Key documents" table
  of `templates/CLAUDE.md.template` + a new `AdoptionHandoffTests` class in
  `skills/scaffold-init/test_scaffold.py` (5 tests).
- **Copy vs. pointer — chose copy (approved plan default):** the guide is
  copied into the scaffolded tree so links resolve locally (AC #3 preferred
  branch). The CLAUDE.md addition is a single short pointer row, not the
  guide body (AC #2; principle 2 — always-loaded context economy).
- **Scaffold-tailored equivalent, NOT a verbatim copy (deviation):** the
  source `docs/adoption-readiness.md` (048-02) links to jig-repo-only paths
  (`../README.md#…`, `specs/033-…`) that have no counterpart in a target
  tree. Copying it verbatim would strand those links. So the template is a
  parallel, scaffold-shaped "Getting started in {{PROJECT_NAME}}" doc whose
  relative links target only scaffold-generated files
  (`product-vision.md`, `architecture.md`, `workflow.md`, `specs/README.md`,
  `specs/001-adopt-jig/spec.md`); the source repo is named via two
  `https://github.com/ramboz/jig` URLs (allowed — not plugin-root/source
  paths). This honors the "don't blindly copy files between projects"
  learning. **Consequence:** the two docs (`docs/adoption-readiness.md` and
  this template) must be kept in rough sync by hand.
- **Seed-spec coupling (noted by both reviewers):** the template links to
  `specs/001-adopt-jig/spec.md`, which exists only because slice 048-05's
  seed emits it into greenfield output. The coupling is satisfied today
  (048-05 is DONE); `test_guide_links_resolve_in_target` would catch a
  dangle if the seed were ever made conditional.
- **Draft marker:** the full suite caught that `test_draft_markers`
  requires every wizard-generated doc to carry `Status: Draft
  (wizard-generated)`; added the standard header (matching
  `CLAUDE.md.template`) rather than excluding the guide — it *is* a
  generated doc. Coverage of the marker is intentionally shared between
  `test_draft_markers` and `AdoptionHandoffTests`.
- **Review:** compliance (`jig:reviewer`) PASS; craft (`pr-review`) PASS.
  No blockers. Two craft nits logged, not actioned (low-stakes): the
  body-inline guard keys on a single heading string ("Your first 30
  minutes") — a thin proxy that weakens if that heading is reworded; AC #2
  is independently protected by context-economy discipline.
- **Tests:** full suite 1470 green (was 1465; +5 here); `spec_lint --all`
  clean. No decisions deferred → no `refinement-todo` entry.
