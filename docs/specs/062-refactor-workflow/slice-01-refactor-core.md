## Slice 062-01 — `refactor.py` core: new / triage / numbering / record / board / claim

**Goal:** you can *create and triage* a refactor — `refactor.py` reserves
a number, writes the `docs/refactors/NNN-slug.md` record, renders the
`docs/refactors/README.md` board, and stamps/refuses a `claimed_by` —
reusing the `_common/` machinery rather than forking it.

**DoR:**
- ✅ ADR-0019 accepted (lifecycle, record schema, tier table).
- ✅ `_common/parsing.py` (`clear_frontmatter_field`, `FRONTMATTER_TRUTHY`)
  and the 049 claim/release pattern exist and are reusable.
- ✅ Spec 058's bug record/board/claim patterns landed (this slice mirrors
  them; if 058 is not yet landed, the patterns are lifted from
  `workflow.py` directly).

**Acceptance Criteria:**

1. **`refactor.py new <slug>`** reserves the next `NNN` and writes
   `docs/refactors/NNN-slug.md` from the ADR-0019 record schema
   (frontmatter: `status` / `tier` / `claimed_by` / `equivalence_oracle`
   / `baseline_ref` / `baseline_confirmed_at` / `equivalence_confirmed_at`
   / `behaviour_delta` / `carved_out_to` / `security_surface` /
   `arch_surface`; body sections per ADR-0019 §5). Local by default.
2. **`refactor.py triage`** classifies a report into `trivial` /
   `standard` / `gnarly` and, for **trivial**, **refuses to create a
   record** — it prints "lean on the existing suite + commit; the
   refactor workflow bows out" (proportionality enforced downward,
   ADR-0019 §4). standard/gnarly proceed to a record.
3. **`refactor.py status-board`** renders/regenerates
   `docs/refactors/README.md` with the ADR-0019 §5 columns (ID / slug /
   tier / oracle / status / baseline? / equivalence? / behaviour-delta /
   claimed_by / carved_out_to), **preserving the Notes column** across
   regen (mirrors the spec/bug boards).
4. **Claim semantics reuse 049:** `claimed_by` is stamped (current branch
   or `JIG_CLAIM_ID`), a foreign still-active claim is **refused** (names
   the holder + points at `--release`), and `--release --reason "<why>"`
   force-clears + logs a release entry. Claims are frontmatter-only.
