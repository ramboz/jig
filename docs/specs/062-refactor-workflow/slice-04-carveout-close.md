## Slice 062-04 — carve-out seam + close/learning + behaviour-delta gate + origin/main reservation

**Goal:** the refactor↔feature seam and the close gate — `refactor.py
carve-out` hands a new-behaviour remainder to `workflow.py new`; `→ DONE`
gates on a behaviour-delta log + a captured learning; and `--push`/`--pr`
reserve the number on `origin/main` via the ADR-0015 path.

**DoR:**
- ✅ 062-03 landed (the lifecycle reaches REVIEWED with evidence).
- ✅ `workflow.py new` (spec reservation) and the ADR-0015 ephemeral-
  detached-worktree-pushed-by-SHA reservation path exist.

**Acceptance Criteria:**

1. **`refactor.py carve-out`** calls `workflow.py new`, stamps
   `carved_out_to: NNN` on the refactor and an "originated from / carved
   out from refactor NNN" note on the new spec. If the *entire* item is
   new behaviour, the refactor parks in terminal **CARVED_OUT** (not
   DONE — nothing was preserved). The new behaviour gets SDD's machinery
   (ADR-0019 §8).
2. **`→ DONE` gates on the behaviour-delta log + learning.** For the
   **gnarly** tier `behaviour_delta` **must be present** (`none` or
   `logged` with the dropped/changed behaviour + rationale); a captured
   `## Learning` is required (presence-check). The gate re-validates the
   ADR-0014 review evidence set. Standard tier requires the learning;
   `behaviour_delta` advisory.
3. **`--push` / `--pr` reserve on `origin/main`** via the uniform ADR-0015
   ephemeral detached worktree at `origin/main`, pushed **by SHA from
   `project_dir`** (the B1 lesson), with the same race / protected-branch
   / PR-fallback handling as `workflow.py new`. Local-by-default unchanged.
4. **Back-edges relax ungated** — `REVIEWED → REFACTORING` (review needs
   changes) and a failed post-equivalence check route back to
   `REFACTORING` carrying the divergence forward as evidence (ADR-0019 §1).
