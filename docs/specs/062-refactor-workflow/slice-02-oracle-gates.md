## Slice 062-02 — pluggable-oracle teeth: baseline-before-edit + equivalence gates

**Goal:** `refactor.py transition` enforces the two distinctive gates —
capture the equivalence baseline **green on unmodified code before any
edit**, then prove it **green / ≥-baseline after** — dispatching on a
**pluggable oracle** (`deterministic` via `tdd.py`, machine-witnessed;
`eval` via attest-only presence + recorded verdict). This is the heart of
the workflow.

**DoR:**
- ✅ 062-01 landed (the record to gate exists).
- ✅ [058-01](../058-bug-fix-workflow/slice-01-tdd-targeted-test.md)
  landed — `tdd.py` runs a single named test with normalized exit codes
  (the deterministic oracle shells out to it). No new `tdd.py` work here.

**Acceptance Criteria:**

1. **`→ BASELINED` declares the oracle and captures green-on-unmodified.**
   For `equivalence_oracle: deterministic`, `refactor.py transition …
   BASELINED` shells to `tdd.py`, **expects exit 0**, and stamps
   `baseline_confirmed_at`; exit 1 (red baseline) and exit 2 (env error)
   both **refuse** (a red/unrunnable baseline proves nothing). For
   `equivalence_oracle: eval`, the gate **refuses unless a `baseline_ref`
   artifact (dataset + recorded score) is present** — jig does not run the
   eval (ADR-0019 §3).
2. **Baseline-before-edit ordering is enforced.** `→ REFACTORING` refuses
   if structural edits to the declared scope predate `baseline_confirmed_at`
   (the anti-"add tests after" rule). The check names the violation.
3. **`→ EQUIVALENCE_CONFIRMED` proves preservation.** deterministic: shells
   to `tdd.py`, **expects exit 0**, stamps `equivalence_confirmed_at`.
   eval: refuses unless a recorded comparison verdict attests **score ≥
   baseline within the stated variance bound**. exit 2 / missing verdict
   **fail closed**.
4. **Deliberateness bypass, two independent vars.**
   `JIG_REFACTOR_BASELINE_GATE=0` and `JIG_REFACTOR_EQUIVALENCE_GATE=0`
   each relax their gate (ADR-0011 lineage; parsed via the shared
   env-bypass idiom). Bypass is a deliberate act, not human-only.
