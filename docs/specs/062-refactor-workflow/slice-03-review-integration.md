## Slice 062-03 — review integration: refactor-review + craft + conditional security + conditional arch

**Goal:** the `→ REVIEWED` transition gates on recorded review evidence —
a refactor-tailored compliance pass + craft (`pr-review`) always, plus
**conditional security** (`security_surface: true`) and **conditional
arch** (`arch_surface: true`) — reusing the ADR-0014 evidence gate.

**DoR:**
- ✅ 062-02 landed (the gated lifecycle reaches REVIEWED).
- ✅ `_common/review_evidence.py` validator + `review.py` prompt builders
  exist (ADR-0014); `pr-review` / `security-review` / `arch-review` skills
  exist and defer to richer installed skills.

**Acceptance Criteria:**

1. **`review.py` builds a refactor-review prompt** (the compliance
   analog) that conditionally/unconditionally checks: does the change
   preserve the declared invariant? Is the equivalence oracle *adequate*
   (does the baseline cover the touched surface, or is it green by
   omission)? Is any `behaviour_delta` honestly logged + justified? Did
   new behaviour sneak in that should be a carve-out (scope creep)?
2. **`→ REVIEWED` gates on the evidence set** (ADR-0014): refuses without
   passing `refactor-review` + `craft` verdicts, naming the missing
   artifact + the `record-review` command. Bypass via the established
   `JIG_REVIEW_EVIDENCE_GATE=0`.
3. **Conditional arch pass** — when `arch_surface: true`, the gate
   additionally requires a passing `arch` verdict (mirrors how
   `arch_review: true` gates SDD's arch pass). When false, no arch
   verdict is required. **This is the key divergence from 058** (bug-fix
   has no arch pass).
4. **Conditional security pass** — when `security_surface: true`, the gate
   additionally requires a passing `security` verdict. Craft + the two
   conditionals defer to richer installed skills where present.

**DoD:**

- [ ] Implementer test coverage exercises each AC with at least one

      required iff `security_surface`; gate refuses + names artifact when
      a verdict is missing) covered explicitly.
- [ ] Reviewed by `reviewer` subagent. Reviewer prompt built by
      `review.py`.
- [ ] Implementation review passed.
- [ ] Deviation log produced under this slice heading.
- [ ] Reconciliation review passed.
- [ ] `docs/refinement-todo.md` updated if any decisions were deferred.
