## Slice 061-01 - committed Claude package + repoint marketplace

**Goal:** Build a runtime-only Claude plugin package, commit it at
`hosts/claude/`, and repoint the root `.claude-plugin/marketplace.json`
at it — so `marketplace add ramboz/jig` installs a clean package instead
of the whole repository.

**DoR:**
- Spec 013 release-zip builder exists (`_INCLUDE_ROOTS` encodes the
  runtime subset).
- Spec 047 install-contract validator exists.
- `scripts/build_codex_plugin.py` establishes the generated-package
  pattern and safe-output guards.

**Acceptance Criteria:**

1. **A Claude package builder exists.** A script/shared helper
   materializes `hosts/claude/` from canonical source: `agents/`,
   `skills/`, `hooks/`, `templates/`, `.claude-plugin/plugin.json`, and
   `README.md` / `LICENSE` when present. It reuses the release-zip
   runtime include/exclude set rather than restating it.
2. **The package is runtime-only.** `hosts/claude/` excludes source-only
   paths (`scripts/`, `docs/`, `.github/`, tests, fixtures, caches) while
   preserving nested runtime paths (`hooks/scripts/`, `templates/docs/`).
   It does **not** contain `.claude-plugin/marketplace.json` or any
   `.codex-plugin/` content.
3. **The root marketplace pointer resolves to the package.** Root
   `.claude-plugin/marketplace.json` points the `jig` plugin `source` at
   the committed `./hosts/claude` package (not `path: "."`), so a remote
   `marketplace add` installs the runtime-only payload with no build step.
4. **Build safety mirrors Codex.** The builder refuses unsafe output
   dirs (source root, source-owned runtime paths, ancestors of the source
   root) and replaces `hosts/claude/` atomically enough for repeatable
   local builds.
5. **The install contract validates the package.** `install_contract.py`
   accepts `hosts/claude/` as the Claude install tree (carrying
   `.claude-plugin/plugin.json` but not the root marketplace.json or
   `.codex-plugin/`), and no longer needs the source root to be the
   Claude artifact.

**Edge cases:**
- Missing optional `LICENSE`/`README.md` → warn, build anyway (parity
  with the release-zip builder).
- A stale pre-existing `hosts/claude/` is fully replaced, not merged.
