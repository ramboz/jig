## Slice 061-02 - host-explicit release archives

**Goal:** Release host-explicit archives named
`jig-claude-vX.Y.Z.zip` and `jig-codex-vX.Y.Z.zip`, built from the
generated host artifacts.

**DoR:**
- Slice 061-01 is DONE.
- `scripts/build_codex_plugin.py` can produce the Codex marketplace
  root at `dist/codex-plugin/`.
- The release workflow currently uploads `jig-vX.Y.Z.zip`.

**Acceptance Criteria:**

1. **Claude archive is built from `dist/claude-plugin/`.**
   `jig-claude-vX.Y.Z.zip` contains the Claude plugin artifact at zip
   root and remains directly usable by Claude's zip/plugin path.
2. **Codex archive is built from `dist/codex-plugin/`.**
   `jig-codex-vX.Y.Z.zip` contains the Codex marketplace root, including
   `.agents/plugins/marketplace.json` and `plugins/jig/.codex-plugin/plugin.json`.
3. **Codex archive language is exact.** Builder output, smoke-test
   output, and docs call the Codex zip an extract-then-add marketplace
   bundle, not a directly installable Codex plugin zip.
4. **Release workflow uploads both host archives.** GitHub release
   packaging builds, smoke-tests, and uploads both host-specific zip
   files.
5. **Compatibility is deliberate.** Either the legacy `jig-vX.Y.Z.zip`
   alias is kept for one release cycle and clearly mapped to the Claude
   archive, or it is removed with README/release-note guidance. The
   decision is recorded in the deviation log.
