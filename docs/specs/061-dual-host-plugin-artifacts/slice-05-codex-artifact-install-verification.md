## Slice 061-05 - Codex artifact install verification

**Goal:** Prove the generated Codex marketplace artifact and Codex
release archive install and run correctly in a real or closest-available
Codex environment, independent of Claude.

**DoR:**
- Slice 061-01 is DONE.
- Slice 061-02 is DONE.
- Slice 061-03 is DONE.
- Slice 061-04 is DONE.
- A Codex CLI is available, or the slice records the exact unavailable
  surface and runs the closest deterministic substitute.

**Acceptance Criteria:**

1. **Generated artifact is verified as Codex-shaped.**
   `dist/codex-plugin/` passes Codex package validation, including the
   marketplace descriptor at `.agents/plugins/marketplace.json` and the
   nested plugin at `plugins/jig/.codex-plugin/plugin.json`.
2. **Codex release archive is verified.** `jig-codex-vX.Y.Z.zip`
   extracts to the expected Codex marketplace-root shape and passes the
   same validation as the generated artifact.
3. **Real Codex install surface is exercised when available.** The slice
   runs a safe Codex marketplace/plugin add probe with an isolated
   `CODEX_HOME`, records the Codex CLI version/surface, and confirms
   skill visibility, hook trust guidance, and explicit Codex agent
   installation behavior.
4. **Fallback is honest when Codex is unavailable.** If a real Codex CLI
   surface cannot be exercised, the slice records why and runs a
   deterministic substitute that validates marketplace shape, manifest
   coherence, rendered Codex skills, hooks, generated TOML agent
   templates, and scaffold helper execution from
   `dist/codex-plugin/plugins/jig/`.
5. **Failure diagnostics name the host.** Any smoke/probe failure output
   clearly identifies the Codex artifact/archive under test so it cannot
   be mistaken for a Claude failure.
