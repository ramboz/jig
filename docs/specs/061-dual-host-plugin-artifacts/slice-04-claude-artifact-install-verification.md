## Slice 061-04 - Claude artifact install verification

**Goal:** Prove the generated Claude artifact and Claude release archive
install and run correctly in a real or closest-available Claude
environment, independent of Codex.

**DoR:**
- Slice 061-01 is DONE.
- Slice 061-02 is DONE.
- Slice 061-03 is DONE.
- A Claude CLI/Desktop environment is available, or the slice records
  the exact unavailable surface and runs the closest deterministic
  substitute.

**Acceptance Criteria:**

1. **Generated artifact is verified as Claude-shaped.**
   `dist/claude-plugin/` passes the existing plugin/install contract and
   contains only Claude-appropriate manifest/runtime paths.
2. **Claude release archive is verified.** `jig-claude-vX.Y.Z.zip`
   extracts to the expected flat Claude plugin shape and passes the same
   contract as the generated artifact.
3. **Real Claude install surface is exercised when available.** The
   slice runs the smallest safe Claude CLI/Desktop install or local
   plugin probe available in the environment and records the command,
   version/surface, and result.
4. **Fallback is honest when Claude is unavailable.** If a real Claude
   install surface cannot be exercised, the slice records why and runs a
   deterministic substitute that validates artifact shape, manifest
   coherence, hooks, skills, agents, and scaffold helper execution from
   `dist/claude-plugin/`.
5. **Failure diagnostics name the host.** Any smoke/probe failure output
   clearly identifies the Claude artifact/archive under test so it
   cannot be mistaken for a Codex failure.
