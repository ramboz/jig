## Slice 061-06 - Claude install verification

**Goal:** Prove the committed `hosts/claude` package and the
`jig-claude-vX.Y.Z.zip` archive install and run correctly in a real or
closest-available Claude environment, independent of Codex.

**DoR:**
- Slices 061-01..05 are DONE.
- A Claude CLI/Desktop environment is available, or the slice records the
  exact unavailable surface and runs the closest deterministic substitute.

**Acceptance Criteria:**

1. **Committed package is verified as Claude-shaped.** `hosts/claude/`
   passes `install_contract.py` and contains only Claude-appropriate
   manifest/runtime paths (no root marketplace.json, no `.codex-plugin/`,
   no `scripts/`/`docs/`/tests).
2. **Remote-install pointer is verified.** The root
   `.claude-plugin/marketplace.json` resolves the `jig` plugin to
   `hosts/claude` (not `path: "."`), and the resolution is asserted.
3. **Claude release archive is verified.** `jig-claude-vX.Y.Z.zip`
   extracts to the expected flat Claude plugin shape and passes the same
   contract as the committed package.
4. **Real Claude install surface is exercised when available.** The slice
   runs the smallest safe Claude CLI/Desktop install or local plugin
   probe available and records the command, version/surface, and result.
5. **Fallback is honest when Claude is unavailable.** If no real Claude
   surface can be exercised, the slice records why and runs a
   deterministic substitute validating package shape, manifest coherence,
   hooks, skills, agents, and scaffold-helper execution from
   `hosts/claude/`.
6. **Failure diagnostics name the host.** Any smoke/probe failure clearly
   identifies the Claude package/archive under test so it cannot be
   mistaken for a Codex failure.

**This is the Claude-side validation pass** (run in a Claude environment;
its Codex sibling is 061-07).
