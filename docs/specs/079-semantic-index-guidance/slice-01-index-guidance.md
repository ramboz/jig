## Slice 079-01 — workflow.md index guidance

**Goal:** Add a short standing-guidance section to `docs/workflow.md`'s
context-cost discipline that tells a reader *when* a semantic/code index
pays for itself, *which* standard options to reach for, and to
detect-installed-then-recommend — so jig's lean-context advice finally
points at the highest-leverage deterministic lever (EngTip #26/#23).

**DoR:**
- ✅ spec 055 (`Context-cost discipline`) section exists in
  `docs/workflow.md` as the home for this guidance.

**Acceptance Criteria:**

1. **The section exists** under the context-cost-discipline guidance in
   `docs/workflow.md`, with a stable anchor, covering: the when (repo
   size / turn-count threshold), the which (portable options centered;
   internal ones "if available"), and the detect-installed-else-recommend
   stance. (Test: anchor/heading present.)
2. **Install-nothing framing is explicit** — the guidance recommends and,
   if a tool is present, orchestrates; it never tells the reader to vendor
   or auto-install an indexer (consistent with `contracts` / `code-health`).
   (Test: the section contains the install-nothing caveat.)
3. **Honest about limits** — the text states a recommendation is not a
   savings guarantee (EngTip #23's "context isn't free" caution). (Test:
   the caveat is present.)
4. **No new always-loaded surface** — the change is `docs/workflow.md`
   only; no new skill, no `.py`, nothing added to `CLAUDE.md`.
