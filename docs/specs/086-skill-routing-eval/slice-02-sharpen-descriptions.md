**Goal:** Act on slice 01's findings — apply *additive* vocabulary edits to the
descriptions the eval flags as mis-routing, fixing at least one real
mis-route and lifting the rank-1 rate, while keeping the committed host
packages in sync.

- ✅ Probe-verified: a SKILL.md description is mirrored into

**Acceptance Criteria:**

1. **Additive-only edits.** Each flagged description is sharpened by *adding*
   the missing user vocabulary to its existing trigger list — no restructuring;
   every phrase the skill's surface test asserts is preserved.
2. **A real mis-route is fixed.** `analyze` gains cross-artifact-drift
   vocabulary for "decision records" (the folder is `docs/decisions/`), so a
   drift query phrased with "decision records" no longer routes to
   `adr-workflow`; `clarify` gains "unclear / unspecified" so that phrasing
   routes to `clarify` rather than `vision-elicitation`.
3. **No regression, measurable improvement.** After the edits: rank-1 rate ≥ its
   pre-edit baseline, negative route-away rate does not decrease, and no
   positive prompt falls out of its `top_k`.
4. **Host packages in sync.** `build_host_packages.py --check` reports in sync,
   and each edited description string appears verbatim in both host copies.
5. **Surface tests intact.** Each edited skill's `test_*_skill_surface.py` still
   passes (proves the edit was additive).
6. **Contested findings documented, not gamed.** Findings that are lexical
   artifacts rather than description defects — the `scaffold-init`/`migrate`
   near-tie (TF-IDF length bias) and the `independent-review`/`slice-land`
   "deviation log" overlap (a genuine shared surface) — are recorded as accepted
   residuals absorbed by the ratchet floor, **not** force-fixed by keyword
   stuffing.
