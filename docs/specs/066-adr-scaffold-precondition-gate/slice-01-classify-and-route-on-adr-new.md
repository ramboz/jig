## Slice 066-01 — classify-and-route-on-adr-new

**Goal:** Replace `adr.py`'s weak, dead-end `docs/decisions/`-presence
check with the three-way `classify_scaffold_state` classification (shipped
by 063-01) so an unscaffolded project reserving an ADR is **routed** to
`/jig:scaffold-init` (greenfield) or `/jig:migrate` (adoptable), while a
scaffolded project reserves exactly as it does today. Consumes the shared
classifier — no new detection.

**DoR:**
- ✅ Spec 063 DONE — `classify_scaffold_state` / `precondition_enabled`
  exist in `skills/_common/scaffold_state.py` and are door-agnostic.
- ✅ Resolved decisions inherited from 063 (bypass=yes via the shared
  `JIG_SCAFFOLD_PRECONDITION`; `scaffold.json`-first; classifier in `_common`).
- ✅ Existing `adr.py` `cmd_new` / `reserve_adr` test suite identified as
  the no-regression baseline.

**Acceptance Criteria:**

1. **`adr.py` reserve path classifies + routes.** The `adr.py new` reserve
   path replaces `if not adrs_dir.is_dir(): raise AdrError(...)` with a
   `classify_scaffold_state(project_dir)` check: `scaffolded` proceeds to
   the existing reserve/scaffold flow unchanged; `adoptable` and
   `greenfield` each refuse with a non-zero exit and a message naming the
   detected state + the exact next command (`/jig:migrate` and
   `/jig:scaffold-init` respectively), creating **no** ADR file and **no**
   reservation commit.
2. **Reuses the shared classifier — no second copy.** `adr.py` imports and
   calls `_common.scaffold_state.classify_scaffold_state`; it does **not**
   re-implement classification or trigger-counting.
3. **Same bypass, shared vocabulary.** `JIG_SCAFFOLD_PRECONDITION`
   (`0`/`false`/`off`/`no`) skips the precondition via the existing
   `precondition_enabled()` and runs the legacy flow. One env var governs
   both the spec (063) and ADR (066) doors.
4. **`scaffolded` proceeds unchanged.** In a `scaffold.json`-bearing
   project (incl. the jig repo itself), `adr.py new` runs the existing
   reserve flow (numbering, file write, commit, push/no-push routing) with
   identical observable output to today. The full pre-existing
   `adr.py`/`reserve_adr` test set stays green.
5. **Per-state test coverage.** Tests exercise each state (scaffolded /
   adoptable / greenfield) plus the bypass path, asserting the refusal
   creates no ADR file / no reservation.

### Deviation log (after reconciliation)

The original spec is preserved above. Implementation notes:

- **Precondition lives in `reserve_adr`, not `cmd_new`.** `adr.py new`
  dispatches to `reserve_adr` (the reserve-on-main flow, slice 028-01);
  `cmd_new`'s line-147 `adrs_dir.is_dir()` check is on a path the CLI never
  takes. The classification was wired into `reserve_adr` (after
  `_validate_slug`, before the `_current_branch` worktree dispatch) so every
  reserve sub-path — on-main, off-main `--no-push`, detached-worktree —
  inherits the routing uniformly. Mirrors 063-01 putting the gate in
  `reserve_spec`. `cmd_new` left untouched (out of scope).
- **Reuses `_common/scaffold_state.py` unchanged (AC2).** Imports
  `classify_scaffold_state` + `precondition_enabled`; no second classifier
  and no trigger-counting in `adr.py`. The classifier file has zero diff.
- **Two defensive `adrs_dir.mkdir(parents=True, exist_ok=True)` added.**
  Removing the top-level `adrs_dir.is_dir()` guard means a
  `scaffold.json`-bearing project lacking `docs/decisions/` would otherwise
  crash at `atomic_write_text` (ADRs are flat files; the parent dir must
  exist). The new mkdirs at the on-main + local-branch write sites mirror the
  pre-existing detached-worktree path. `reserve_spec`'s analogue needed none
  because spec dirs are created via `spec_dir.mkdir(parents=True)`.
- **Existing reserve fixtures gained a `scaffold.json` sentinel (AC4
  no-regression)** — mirrors 063-01's fixture fix (a bare `docs/decisions/`
  is now `greenfield`, so reserve-invoking fixtures write a `scaffold.json`
  to classify `scaffolded`). One pre-existing test renamed
  (`test_new_refuses_when_decisions_dir_absent` →
  `test_new_refuses_when_unscaffolded`): it asserted the old dead-end message;
  it now asserts greenfield→`/jig:scaffold-init` routing. The legacy weak
  refusal stays covered under bypass by `test_bypass_preserves_legacy_weak_refusal`.
