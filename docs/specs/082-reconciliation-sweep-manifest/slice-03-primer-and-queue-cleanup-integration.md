## Slice 082-03 — primer and queue cleanup integration

**Goal:** Rename reconciliation cleanup from Claude-specific `CLAUDE.md hygiene`
to host-portable primer hygiene, document the sweep workflow, and clean up
already-resolved inbox/refinement items exposed by this spec.

**DoR:**
- ✅ Slices 082-01 and 082-02 have landed the manifest gate and reviewer check.
- ✅ v2-owned `AGENTS.md` details are checked before editing branch-specific
  primer guidance; main-branch docs must not invent v2 file content.

**Acceptance Criteria:**

1. **Spec-workflow names primer hygiene.** The reconciliation checklist in
   `skills/spec-workflow/SKILL.md` refers to primer hygiene covering
   `CLAUDE.md`, `AGENTS.md`, and scaffold templates when present. It preserves
   the spec 025 compress-on-close-out rule but removes the Claude-only framing.
2. **Workflow docs explain the sweep.** `docs/workflow.md` and the relevant
   skill guidance explain when to write the sweep, how to use the three
   dispositions, and how to keep live prose inline-correct per ADR-0010.
3. **Queue cleanup is dogfooded.** `docs/inbox.md` and
   `docs/refinement-todo.md` are searched for entries resolved by spec 082 or
   by already-landed cleanup. Resolved entries are struck through or promoted
   to memory; still-valid entries keep their trigger with a short rationale.
4. **Front-door stale claims are reduced.** Any stale live claim discovered
   while implementing this spec in `README.md`, `docs/product-vision.md`, or
   `docs/architecture.md` is either corrected inline or recorded as a
   `deferred` sweep item with an owner/trigger.
5. **Tests or docs pin the new wording.** Existing prose tests are updated, or
   a focused docs check is added, so future edits do not reintroduce the
   Claude-only `CLAUDE.md hygiene` gate name where primer hygiene is intended.
