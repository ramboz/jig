## Slice 058-03 — gated transitions: diagnose gate + red→green teeth + fix_class

**Goal:** `bug.py transition` drives the lifecycle and enforces the two
distinctive teeth gates — diagnose-before-fix (≥2 hypotheses) and the
**red→green** proof that shells to `tdd.py` to witness the regression
test fail before the fix and pass after.

**DoR:**
- ✅ 058-01 (`tdd.py run --test <selector>` with normalized exit codes).
- ✅ 058-02 (a `docs/bugs/NNN-slug.md` record with the schema to gate on).

**Acceptance Criteria:**

1. **`transition <id> ROOT_CAUSED` is gated by the diagnose gate:**
   refuses unless the record carries ≥2 candidate hypotheses + a leading
   one + an evidence pointer. **Mandatory for gnarly**, advisory (warn,
   not block) for standard. Bypass `JIG_BUG_DIAGNOSE_GATE=0`
   (deliberateness signal). Refusal names what is missing.
2. **`transition <id> FIXING` is gated by `fix_class` + red:** refuses
   unless `fix_class` is declared (one of the ADR-0016 enum) **and**
   `tdd.py run --test <regression_test>` exits **1 (red)**. On success it
   stamps `red_confirmed_at`. A `tdd.py` env error (exit 2) **fails
   closed** with a message distinct from "test passed unexpectedly"
   (exit 0 here → refuse: "the regression test passes without a fix — it
   does not capture the bug").
3. **`transition <id> REVIEWED` (test half) is gated by green:** refuses
   unless `tdd.py run --test <regression_test>` exits **0 (green)**;
   stamps `green_confirmed_at`. Bypass `JIG_BUG_TEST_GATE=0`. (The
   review-evidence half of the REVIEWED gate is added in 058-04.)
4. **Back-edges relax without gating, and accrue evidence:** a failed
   green-check (or a later "symptom-not-cause" verdict) routes the record
   back to `DIAGNOSING` and appends the failed attempt to the record's
   `## Already tried` section rather than silently looping.
5. **Ungated transitions keep simple status-set behaviour**
   (`REPORTED → DIAGNOSING`, etc.), validating only status membership and
   legal ordering.
