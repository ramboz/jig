## Slice 058-04 — review integration: bug-review + craft + conditional security

**Goal:** the `REVIEWED` transition also gates on recorded, passing review
evidence — a bug-tailored review pass plus the reused craft and
conditional security passes — reusing `_common/review_evidence.py`.

**DoR:**
- ✅ 058-03 (the `REVIEWED` test-half gate exists to extend).
- ✅ `_common/review_evidence.py` (ADR-0014 verdict artifact + validator).

**Acceptance Criteria:**

1. **A bug-tailored reviewer prompt is built** (by `review.py`, under a
   bug pass name e.g. `bug-compliance`) covering: root-cause vs symptom;
   a regression test that fails without the fix; blast radius; scope
   creep; and — if `fix_class: workaround` — whether the workaround is
   honestly labelled and justified.
2. **`transition <id> REVIEWED` gates on passing verdicts**, reusing the
   ADR-0014 evidence gate: **bug-review** (always) **and** **craft**
   (`pr-review`, always) **and** **security** (`security-review`, iff
   `security_surface: true`). Each clears iff `verdict: pass`.
3. **A blocked transition names the missing/failing pass** and the
   `record-review` command that produces it (mirrors `workflow.py`
   refusal diagnostics).
4. **`security_surface` is parsed via the shared `FRONTMATTER_TRUTHY`**
   set (no second truthy convention).

**DoD:**
- [ ] All ACs pass; full test suite green (no regressions).
- [ ] Implementer test coverage exercises each AC with at least one
      fixture. Edge cases (security pass required only when
      `security_surface: true`; missing bug-review → named refusal)
      covered explicitly.
- [ ] Reviewed by `reviewer` subagent. Reviewer prompt built by
      `review.py`.
- [ ] Implementation review passed.
- [ ] Deviation log produced under this slice heading.
- [ ] Reconciliation review passed.
- [ ] `docs/refinement-todo.md` updated if any decisions were deferred.
