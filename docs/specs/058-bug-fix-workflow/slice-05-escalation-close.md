## Slice 058-05 — escalation seam + close/learning gate + origin/main reservation

**Goal:** complete the lifecycle ends — the `ESCALATED` off-ramp to a
spec, the `DONE` close gate (review verdicts + a recorded learning), the
`VERIFIED` step for gnarly/security, and `--push`/`--pr` reservation of
the bug number on `origin/main` via the ADR-0015 path.

**DoR:**
- ✅ 058-02 (record + local numbering + claim).
- ✅ 058-03 (gated transitions).

**Acceptance Criteria:**

1. **`bug.py escalate <id>` opens a spec and parks the bug:** it calls
   `workflow.py new`, stamps `escalated_to: NNN` on the bug and
   "originated from bug NNN" on the new spec, and sets the bug to
   terminal **`ESCALATED`** (distinct from `DONE` — it was not fixed as a
   bug).
2. **`transition <id> DONE` is gated on close evidence:** refuses unless
   the required review verdicts (058-04) re-validate as pass **and** a
   learning is recorded in `docs/memory/learnings.md` (presence-check).
   Refusal names the missing piece.
3. **`bug.py new --push` / `--pr` reserves the number on `origin/main`**
   via the ADR-0015 ephemeral detached-worktree at `origin/main`, pushed
   **by SHA from `project_dir`**; local-by-default otherwise.
   Race-on-push / protected-branch handling mirrors `workflow.py new`
   (drops the stranded commit + file; PR-fallback when push refused).
4. **`VERIFIED` is enforced for gnarly/security tier:** `→ VERIFIED`
   requires an attested re-run of the *original reported repro* (recorded
   in the `## Proof` section) before `DONE`; trivial/standard tiers
   transition `REVIEWED → DONE` directly.

### Deviation log (after reconciliation)

The original spec is preserved above. Implementation notes:

- **All four ACs met as specified.** `escalate` links bug↔spec both
  directions and parks the bug `ESCALATED` (AC1); `DONE` re-validates
  review evidence + a recorded learning (AC2); `--push`/`--pr` reserve on
  `origin/main` via the ADR-0015 detached worktree, pushed by SHA from
  `project_dir`, with race/protection handling (AC3); `VERIFIED` is
  enforced for gnarly/security before `DONE` (AC4).

- **Gates are presence/deliberateness checks, by design — not proofs.**
  `_proof_attests_original_repro` matches the literal "original reported
  repro" in `## Proof` (AC4), and `_learning_recorded` is a substring
  presence-check against `docs/memory/learnings.md` (AC2). Both are
  deliberate per the spec's wording ("recorded in `## Proof`",
  "presence-check") and consistent with the spec-gate model
  ([ADR-0011](../../decisions/adr-0011-spec-gate-model.md)) — they signal
  deliberateness, real control is out-of-band. A reviewer flagged the
  literal-substring brittleness; left as-is to match AC intent.

- **Single-path reservation (deliberate divergence from `workflow.py new`).**
  `reserve_bug_on_origin` always reserves via the ephemeral detached
  worktree at `origin/main`, regardless of the caller's branch — whereas
  `workflow.py`'s `reserve_spec` dispatches on-main (in-place) vs off-main
  (detached). This follows the slice's explicit prescription ("the
  ADR-0015 ephemeral detached-worktree") and ADR-0015's deferred option;
  it is not an oversight.

- **Reservation machinery is inline-mirrored, not extracted.**
  `_classify_push_failure`, `_check_gh_and_remote`,
  `_push_bug_reservation_pr`, and the detached-worktree dance duplicate
  the `workflow.py` reservation shape rather than living in
  `_common/`. Correct under the extract-at-third-caller rule
  ([ADR-0002](../../decisions/adr-0002-no-internal-contracts-scope.md)) —
  `bug.py` is the next independent reservation consumer after
  `workflow.py`/`adr.py`. The next consumer should trigger extraction;
  logged to [docs/inbox.md](../../inbox.md).

- **Post-review test addition.** Compliance review (needs-changes) flagged
  that AC3's `--pr` mode and the protected-branch PR-fallback branch had
  no coverage (only the push-race path did). Added
  `test_pr_mode_reserves_via_branch_and_opens_pr`,
  `test_protected_branch_push_falls_back_to_pr`, and
  `test_pr_fallback_refuses_when_gh_missing`; compliance re-cleared.
