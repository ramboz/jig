## Slice 032-01 — atomic-write-helper

**Goal:** Add `atomic_write_text(path, content)` to
`skills/_common/atomic_io.py` and sweep every `Path.write_text(...)` in
jig's helper scripts to use it. After this slice, no individual file
write in `scaffold.py`, `workflow.py`, `memory.py`, `adr.py`, `land.py`,
or `review.py` can leave a torn file behind if the process is interrupted
mid-write.

**DoR:**
- ✅ `_common/` is already a shared module location (mirrors
  `_common/parsing.py` precedent).
- ✅ `_common/` is now copied at scaffold time (per the 2026-05-20 fix
  on main), so scaffolded users get this helper too.
- ⏳ Audit of `Path.write_text` callsites confirmed by the implementer
  (see AC #3 for the expected list).

**Anti-horizontal-phasing check.** Vertical: a jig user runs any helper
that produces a file (e.g., `workflow.py transition`, `scaffold.py`,
`adr.py new`); if the process is interrupted mid-write, the on-disk file
is either fully the old content or fully the new — never a half-written
hybrid. Crosses all layers: `_common/atomic_io.py` (new), every helper
`.py` that writes user-visible files (modified), and the on-disk
filesystem semantics (existing — POSIX rename).

**Acceptance Criteria:**

1. **`skills/_common/atomic_io.py` exists** with a single public function
   `atomic_write_text(path: Path, content: str, *, encoding: str =
   "utf-8") -> None`. Implementation: write to a temp file created by
   `tempfile.NamedTemporaryFile(delete=False, dir=path.parent,
   suffix=".tmp")`, then `os.replace(tmp, path)`. On any exception
   during write or replace, the temp file is best-effort removed
   (try/except OSError) before re-raising.

2. **`atomic_write_text` is unit-tested** in
   `skills/_common/test_atomic_io.py`. Cases:
   (a) happy path overwrites an existing file with new content;
   (b) happy path creates a new file when the destination doesn't exist;
   (c) the tmp file is in `path.parent` (verified by monkey-patching
   `tempfile.NamedTemporaryFile` to capture the `dir=` argument);
   (d) an exception during the `os.replace` call cleans up the tmp file
   (mock `os.replace` to raise; assert no leftover `.tmp` in
   `path.parent`);
   (e) unicode content round-trips correctly (utf-8 encoding).

3. **Every `Path.write_text(...)` callsite in helpers is replaced** with
   `atomic_write_text(...)`. The sweep targets:
   `skills/scaffold-init/scaffold.py`, `skills/spec-workflow/workflow.py`,
   `skills/memory-sync/memory.py`, `skills/adr-workflow/adr.py`,
   `skills/slice-land/land.py`, `skills/independent-review/review.py`.
   **Excluded** from the sweep: test files (`test_*.py`) and any
   `write_text` on paths that are NOT user-visible state (none in
   helper code today). The implementer's deviation log records the
   exact callsite count before and after.

4. **Regression sweep guard.** A new test
   `skills/_common/test_atomic_io_sweep.py` greps each targeted helper
   `.py` file for `\.write_text\(` and asserts the count is zero.
   Catches future re-introduction of non-atomic writes in the swept
   helpers. The test reads files from disk (no import side effects).

5. **Helpers import the new symbol via the existing `_common` pattern.**
   Each modified helper gains `from _common.atomic_io import
   atomic_write_text` near the existing `from _common.parsing import
   ...` import block.

6. **No regression in existing tests.** Full suite green
   (`python3 scripts/run_tests.py` exits 0). Test count delta recorded
   in deviation log.
