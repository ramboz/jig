## Slice 045-03 - lifecycle-transition-gates

**Goal:** Make `workflow.py transition` refuse review and reconciliation
status moves unless the required evidence exists and validates.

**DoR:**
- Slice 045-02 is DONE.
- The validator has fixtures for each required pass and each failure
  mode.
- The transition map in the ADR is accepted and unambiguous.

**Acceptance Criteria:**

1. **`REVIEWED` is gated.** Transitioning a slice to `REVIEWED` fails
   when required implementation/craft/arch evidence is missing,
   malformed, failed, or superseded without a later pass, and succeeds
   when valid passing evidence is present.
2. **`RECONCILED` and `DONE` are gated.** Transitioning past review
   fails when the deviation log or reconciliation evidence required by
   the ADR is missing or invalid.
3. **Diagnostics are specific.** Refusals name the missing or invalid
   artifact and the command a contributor should run next.
4. **Existing safe transitions still work.** Drafting, deferring,
   reopening deferred slices, and status-board regeneration keep their
   existing behavior unless the ADR explicitly changes them.

### Deviation log (after reconciliation)

The original spec is preserved above. Implementation notes:

**Deliverables.** The gate is wired into `workflow.py transition()`
(`_EVIDENCE_GATED_STATES`, `_gate_evidence`, `_evidence_gate_enabled`),
delegating to `review_evidence.validate_evidence` (045-02) — no
reimplementation. `check_deviation_log` and the `arch_review` truthy
predicate were lifted into `_common/parsing.py` (`FRONTMATTER_TRUTHY`,
`frontmatter_flag_truthy`, `check_deviation_log`); `review_evidence.py`,
`workflow.py`, and `land.py` now share them. `skills/spec-workflow/SKILL.md`
gained a brief gate + bypass note. 40 new tests (31 workflow + 9 parsing).

**Transition map enforced (ADR-0014 §5).** → REVIEWED needs
compliance + craft (+ arch iff `arch_review` truthy); → RECONCILED needs the
reconciliation verdict AND a present deviation log (via the lifted
`check_deviation_log`); → DONE re-validates the full set AND keeps the
existing dependency check. Ungated (AC4): DRAFT / READY_FOR_REVIEW /
READY_FOR_IMPLEMENTATION / IN_PROGRESS / DEFERRED, DEFERRED→DRAFT, and the
back-edges REVIEWED→IN_PROGRESS / RECONCILED→IN_PROGRESS.

**Unification (045-02 hand-off, done).** `_ARCH_REVIEW_TRUTHY` in both
`workflow.py` and `review_evidence.py` now alias the single
`parsing.FRONTMATTER_TRUTHY` object — pinned by an `assertIs` identity test
so the orchestrator and the gate cannot drift. `check_deviation_log` lives in
`_common` (not `land.py`) so the gate reuses it without a cross-skill import
(ADR-0014 §5 sanctions the `_common` move).

**Backward-compat.** The only in-process `transition()` caller is the CLI;
every test drives it as a subprocess via `run_workflow()`, which now defaults
to `JIG_REVIEW_EVIDENCE_GATE=0`. So the ~14 pre-existing
transitions-to-gated-states stay green unchanged, while the new gate tests run
with the gate ON. Production callers (`land.py`, `scaffold.py`) do **not** call
`transition()`; landing-without-evidence is transitively blocked (a slice
cannot reach DONE without passing the gate).

**Bypass + ADR consistency.** `JIG_REVIEW_EVIDENCE_GATE`
(`0`/`false`/`off`/`no`, case-insensitive) is a deliberateness escape hatch
consistent with ADR-0014 §6 / ADR-0011 — the gate "enforces evidence
consistency, not human sign-off" and lives in the agent's trust boundary
(mirrors `JIG_CONVENTIONS_APPROVED`, `JIG_BOUNDARY_CHECK`). It is documented in
`SKILL.md`. **ADR-0014 was deliberately NOT edited** (immutable Accepted record
per ADR-0006); the bypass *implements* its §6 stance rather than changing the
decision. Both reviewers (compliance + craft) confirmed no blocking ADR
amendment is required.

**Review.** Compliance + craft, both independent `jig:reviewer`, prompts built
by `review.py` → both **pass**, 0 blockers. The compliance reviewer verified
the highest-risk question rigorously: the gate is genuinely exercised ON — the
new tests assert both *refusal* (status unchanged, non-zero exit) and
*clearance* for every AC with the env unset, so a neutered or over-eager gate
cannot ship with the suite green.

**Self-hosting proof.** 045-03's own REVIEWED/RECONCILED/DONE transitions were
gated by the gate it built — evidence recorded via `review.py record-review`
and the transitions run with `JIG_REVIEW_EVIDENCE_GATE` unset (gate ON). The
mechanism now gates its own development.

post-review code change — `test_land.py` uses `check_deviation_log`
