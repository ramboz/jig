## Slice 045-02 - review-artifact-recorder

**Goal:** Add the helper and schema support needed to record and validate
review evidence for a single slice.

**DoR:**
- Slice 045-01 is DONE and the accepted ADR names the evidence storage
  path and schema.
- Fixture slices exist for at least: compliance pass, craft pass,
  optional arch pass, reconciliation pass, failed verdict, and
  superseded verdict.

**Acceptance Criteria:**

1. **Helper can write evidence.** A documented command records a review
   pass for a target slice with pass type, verdict, reviewer source,
   timestamp, prompt source, and freeform summary fields required by the
   ADR.
2. **Helper can validate evidence.** A documented command validates the
   evidence set for a target slice and exits non-zero with actionable
   diagnostics for missing files, malformed frontmatter, unknown pass
   names, unknown verdicts, stale/superseded-only evidence, and invalid
   slice targets.
3. **Evidence is reviewable.** The chosen artifact format is plain text
   or structured text that renders cleanly in a normal code review, and
   generated sections are stable across repeated runs.
4. **Scaffold mode includes the helper.** A scaffolded project receives
   the same recorder/validator path if the accepted ADR chooses
   scaffold-portable storage.

## Amendments

- **2026-07-30 — bug 017: the verdict body is no longer optional.** This slice
  logged, as shipped behaviour, that "an empty body and a one-newline body
  serialize byte-identically (body is optional)". `record-review` now refuses
  both: a missing `--summary-file`, and a source that resolves to whitespace,
  each exit 2. The body is required on all three targets (slice, `--adr`,
  `--bug`). See [bug 017](../../bugs/017-record-review-blocks-on-stdin.md).

  The optional body was not itself the defect — the stdin fallback that made it
  reachable was, and it hung any caller handed a pipe nobody closes. Requiring
  the body is the direction the maintainer chose on
  [#144](https://github.com/ramboz/jig/pull/144) once that fallback had to go:
  a recorded review with no reasoning is evidence in name only. Frontmatter
  serialization is unchanged; only the refusal is new.
