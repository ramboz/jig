wording, and tests with the now-enforced review evidence lifecycle.

  covering the happy path from implementation review through DONE.

**Acceptance Criteria:**

1. **Docs describe the enforced path.** `docs/workflow.md`,
   `skills/spec-workflow/SKILL.md`, and

   record verdict evidence, transition statuses, reconcile, and recover
   from failed reviews.

   and plugin-mode docs point at commands that exist in that install
   shape.
