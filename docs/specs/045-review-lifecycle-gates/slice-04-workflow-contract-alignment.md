## Slice 045-04 - workflow-contract-alignment

**Goal:** Align the user-facing workflow, implementer instructions, hook
wording, and tests with the now-enforced review evidence lifecycle.

**DoR:**
- Slice 045-03 is DONE.
- The transition-gate behavior has at least one end-to-end fixture
  covering the happy path from implementation review through DONE.

**Acceptance Criteria:**

1. **Docs describe the enforced path.** `docs/workflow.md`,
   `skills/spec-workflow/SKILL.md`, and
   `skills/independent-review/SKILL.md` describe how to build prompts,
   record verdict evidence, transition statuses, reconcile, and recover
   from failed reviews.
2. **Agent instructions stop over-claiming.** `agents/implementer.md`
   no longer tells the implementer to mark work `REVIEWED` directly
   unless the evidence gate can pass.
3. **Hook claims are honest.** Any claim that a Stop hook blocks
   unreconciled completion is either backed by deterministic hook
   behavior or rewritten to the actual helper/gate behavior.
4. **Release/scaffold docs inherit the flow.** Generated scaffold docs
   and plugin-mode docs point at commands that exist in that install
   shape.

**DoD:**
- [ ] All ACs pass; full test suite green (no regressions).
- [ ] Implementer test coverage exercises each AC with at least one
      fixture. Edge cases listed in the slice are covered explicitly.
- [ ] Reviewed by `reviewer` subagent. Reviewer prompt built by
      `review.py`.
- [ ] Implementation review passed.
- [ ] Deviation log produced under this slice heading.
- [ ] Reconciliation review passed.
- [ ] `docs/refinement-todo.md` updated if any decisions were deferred
      during implementation.

### Close-out (post-DONE)

- [ ] `docs/specs/README.md` regenerated by `workflow.py status-board`.
- [ ] `CLAUDE.md` hygiene per spec 025-01 rule.

**Anti-horizontal-phasing check:** After this slice lands, a contributor
following the docs and agent guidance sees the same lifecycle that the
tools enforce.
