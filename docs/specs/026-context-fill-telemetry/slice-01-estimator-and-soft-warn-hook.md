## Slice 026-01 — estimator-and-soft-warn-hook

**Goal:** Replace `jig-context-check.sh`'s MCP-server proxy with a
byte-based context-fill estimator and a soft warning emitted as
`additionalContext` once the loaded-bytes estimate crosses the
configured threshold. No refusal behavior — warning only.

**DoR:**
- ✅ Spec 025 (CLAUDE.md hygiene) DONE, so the primer-doc baseline
  is stable.
- ✅ Existing hook (`hooks/scripts/jig-context-check.sh`) still
  fires on `SessionStart` and is registered in `hooks/hooks.json`.

**Acceptance Criteria:**

1. **Byte-based estimate.** A new Python helper (path TBD, likely
   `scripts/context_fill.py` or `hooks/scripts/lib/context_fill.py`)
   takes the project root and returns `{bytes, est_tokens, ratio,
   threshold, breakdown}` for always-loaded artifacts: CLAUDE.md,
   `docs/memory/*.md` if present, and any file an
   `auto_attachments`-style mechanism would load. `est_tokens =
   bytes // RATIO` with `RATIO = 4` (documented as a rough
   English-prose heuristic in the module docstring).
2. **Threshold configurable via env var.** `JIG_CONTEXT_SOFT_WARN_PCT`
   overrides the default (30% of `JIG_CONTEXT_WINDOW_BYTES`, default
   sized for Opus 4.7). Both vars documented in the script header.
3. **Warning surfaced as `additionalContext`.** When `ratio >=
   threshold`, the hook emits `{"continue": true, "additionalContext":
   "..."}` naming the actual byte count, the threshold, and a
   one-sentence suggestion (run `/jig:memory-sync` and/or `/compact`).
4. **MCP-server check preserved.** Existing MCP-server-count branch
   stays (still useful for catching tool-description bloat); both
   warnings can coexist in one emission.
5. **No refusal.** The hook never sets `continue: false`. A test pins
   this.
6. **Estimator is unit-tested.** New tests assert: empty repo → 0
   bytes; CLAUDE.md only → correct byte count; mixed files → correct
   aggregation; threshold crossing emits warning; threshold not
   crossed emits nothing (or only MCP warning).
7. **No regression in existing MCP-server count tests.** Whatever
   tests currently cover `jig-context-check.sh` continue to pass.
