- [2026-05-18] **`spec-workflow/transition/status-marker-clobber:`** `workflow.py transition`'s status-rewrite regex `(\*\*STATUS:\s*)([A-Z_]+)(\*\*)` matches the FIRST occurrence anywhere in the slice section body, not the slice's own status line. Hit on slice 030-01 during the REVIEWED → RECONCILED transition: the deviation log contained a prose example with surrounding asterisks (quoting another slice's STATUS marker), and the transition clobbered DRAFT → RECONCILED in the example text. Workaround: reword prose to drop the asterisks (current slice did this).
