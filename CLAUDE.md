### Key terms
- **Lifecycle-family spine** — [ADR-0023](docs/decisions/adr-0023-lifecycle-family-spine.md) — spec-workflow / `jig:bug-fix` (ADR-0016) / `jig:refactor` (ADR-0019) are one governed family of gated-evidence lifecycles sharing a C1-C7 spine contract (durable-evidence gates / deliberateness-not-sign-off / claimable record / downward de-escalation / pluggable oracle / reuse `_common/` / escape seam). Convergence rule (rule-of-three): members inline-mirror until the *third concrete `transition` implementation*, which triggers extraction to `_common/lifecycle.py` — not before (today only `workflow.py` exists; bug.py/refactor.py are Proposed). The pluggable-oracle boundary to servo ([ADR-0022](docs/decisions/adr-0022-pluggable-oracle-boundary.md), spine clause C5) is PARKED — ahead of demand per ADR-0019's trigger; do not re-propose without a real eval case, servo spec 006 shipping, or a built consumer.
- **Closed-spec drift policy** — [ADR-0010](docs/decisions/adr-0010-amendment-scope-records-vs-live-prose.md) (supersedes [ADR-0008](docs/decisions/adr-0008-closed-spec-drift-policy.md)) — **records** (closed DONE / SUPERSEDED specs + slices) get a `## Amendments` section that preserves the original; **live operational prose** (SKILL.md descriptions, `docs/workflow.md`, README) is corrected **inline**, with git history as the audit trail. New ADR (or superseding spec) for decision-content changes. Excludes IN_PROGRESS / REVIEWED / RECONCILED / DEFERRED.

- **Spec-gate model** — [ADR-0011](docs/decisions/adr-0011-spec-gate-model.md) — `hooks/scripts/jig-spec-gate.sh` is a *deliberateness* gate that blocks accidental side-effect edits to `docs/conventions.md`, **not** human-only enforcement (the `JIG_CONVENTIONS_APPROVED=1` env var is satisfiable by any shell, incl. the agent via Bash). Real human-only control is out-of-band (`CODEOWNERS` / CI / branch-protection). The *policy* "human approval to change conventions.md" stays; only the claim that the *hook enforces* it was the honesty gap. Gate is jig-layout-specific (`docs/conventions.md` only; `JIG_GATED_FILES` deferred).

- **Security floor** — [ADR-0013](docs/decisions/adr-0013-security-floor-policy.md) / [spec 052](docs/specs/052-security-scaffold/spec.md) — every scaffolded/migrated project gets a 5-part floor: `.gitignore` secret patterns (with `!.env.example` re-includes) + an agent-time `jig-secret-scan.sh` PreToolUse hook (blocks high-confidence secrets — AWS key / PEM / secret-named `.env` assignment — overridable via `JIG_SECRET_SCAN_APPROVED=1`, fails open) + conservative `permissions.deny` defaults (force-push / hard-reset / `rm -rf`, merged by **set-membership** marker since a string array can't carry the hooks' `metadata.managed_by_jig`) + a lean `## Security (MUST)` CLAUDE.md block + the slim Tier-1 `jig:security-review` skill (orchestrate-installed-scanners + defer-to-richer). **Defense-in-depth, not a firewall** (mirrors [ADR-0011](docs/decisions/adr-0011-spec-gate-model.md)): real enforcement is out-of-band (CI / server-side hooks / branch protection). Non-exhaustive by design; tuning surfaces parked in `docs/refinement-todo.md`. The floor flows to existing projects via `migrate copy-machinery` and is asserted by `scripts/verify_install.py`.
- **Review-evidence gate** — [ADR-0014](docs/decisions/adr-0014-review-evidence-model.md) (spec 045) — review/reconciliation verdicts are durable artifacts at `docs/specs/NNN-slug/reviews/slice-NN-<pass>.md` (frontmatter: `slice`/`pass`/`verdict`/`reviewer`/`reviewed_at`/`prompt_source`; body = the VERDICT envelope). `review.py record-review` writes them, `check-reviews` validates. `workflow.py transition` **gates** READY_FOR_REVIEW (frame-critique iff `frame_review` — spec 064-03, the **only PRE-implementation** gate; not re-validated at DONE), REVIEWED (compliance+craft, +arch iff `arch_review`, +code-health iff `code_health_review` — spec 060-05, +design-review iff `design_review` — spec 071-01, **attest-only**), RECONCILED (reconciliation verdict + deviation log via `check_deviation_log`), DONE (re-validates the REVIEWED+RECONCILED set + dep-check) — each clears iff `verdict: pass`; refuses naming the missing artifact + the `record-review` command. Bypass `JIG_REVIEW_EVIDENCE_GATE=0` (deliberateness signal per ADR-0011, **not** human-only). Supersede = overwrite-in-place + git history (ADR-0010). Shared schema/validator: `skills/_common/review_evidence.py` (`PASSES` = compliance/craft/arch/**code-health**/reconciliation/**frame-critique**/**design-review**; `required_passes` is the sole stage→passes map; `validate_evidence` reads the `arch_review`/`code_health_review`/`frame_review`/`design_review` flags itself so spawner+gate can't drift); flag-truthy set unified in `skills/_common/parsing.py` (`FRONTMATTER_TRUTHY`). The review passes each leave a verdict artifact the gate checks; arch + code-health + design-review (REVIEWED) and frame-critique (READY_FOR_REVIEW) are **gated** on their per-slice frontmatter flags (default-off → existing slices unaffected). **Frame-critique** (spec 064 / [ADR-0020](docs/decisions/adr-0020-spec-frame-hardening.md), all 5 slices DONE) is the adversarial *frame*-hardening pass — hunts the riskiest load-bearing assumption pre-implementation, NOT conformance; equal-or-stronger model policy, never downgrade for cost. Full loop shipped: probe-first grounding + risk-gated `## Assumptions`/`## Kill criteria` (064-02), spec-side READY_FOR_REVIEW gate (064-03), derived trigger (`derive_frame_review`/`frame-review-needed` off the spec's `## Assumptions`) + `session-plan` dispatch (064-04), and the ADR-side `adr.py accept` gate + `record-review --adr` + ADR evidence at `docs/decisions/reviews/adr-NNNN-<pass>.md` (064-05 — ADRs always-on via a `new`-stamped `frame_review` marker, legacy markerless ADRs grandfathered; `evidence_gate_enabled` shared from `_common` so both gates can't drift). Rung-3 cross-model critique deferred (`docs/refinement-todo.md`, OQ4). **Design-review** (spec 071-01 / [ADR-0022](docs/decisions/adr-0022-pluggable-oracle-boundary.md)) is the **attest-only** REVIEWED-stage pass (sibling of arch): a read-only reviewer attests an external non-deterministic design-fidelity eval's frozen verdict (e.g. servo's `.servo/design-eval/` composite ≥ its own threshold, non-stale, `env_error` ≠ pass), never re-deriving the score — servo runs/scores, jig attests (ADR-0022 honesty boundary; resolved ADR-0022's spec-gate OQ + ADR-0019 OQ2).
- **Worktree-aware reservation** — [ADR-0015](docs/decisions/adr-0015-worktree-aware-reservation.md) / [spec 051](docs/specs/051-worktree-aware-reservation/spec.md) (051-01/02 DONE; 051-03 land-guardrail DEFERRED) — `workflow.py new` / `adr.py new` **route on the current branch** instead of refusing off-main. On `main`: the proven 003-03/037-02 in-place flow, unchanged. Off `main` (feature branch / linked worktree), push mode: build the reservation commit in an **ephemeral detached worktree** at `origin/main` (`git worktree add --detach`), push it **BY SHA from `project_dir`** (the B1 lesson — pushing from the temp worktree breaks relative-`origin` repos), tear the worktree down in a `finally` (remove --force + prune). Off `main` `--no-push`: provisional commit on the current branch, pathspec-scoped so unrelated staged work isn't swept in. Caller's branch/cwd/tree never touched. Inline-mirrored across both helpers (two callers; ADR-0002's extract-trigger is three). Best-effort serialization (defense-in-depth, like ADR-0011/0013); the durable land-time collision backstop is the deferred 051-03.
- **Context-cost discipline** — [spec 055](docs/specs/055-context-cost-discipline/spec.md) — the orchestrator's context is the most expensive real estate (re-read every turn → cost ≈ context-size × turns; measured on jig: ~90% orchestrator / ~97% `cache_read` / ~4% baseline — in-session *growth*, not the primer, is the cost). Four soft, non-blocking, scaffolded mechanisms keep it lean: (01) **delegate** file-heavy reading to a read-only built-in `Explore`/`general-purpose` subagent, keep only the summary; (02) **growth nudge** — `jig-context-check.sh` on `UserPromptSubmit` warns past dumb-zone bands (`JIG_CONTEXT_GROWTH_WARN_PCT`; 40/60/80; re-arm-on-drop); (03) **read-once/lean** — `PreToolUse(Read)` warns duplicate / oversized (`JIG_READ_LEAN_BYTES`) reads; (04) **verbose-Bash** — the implementer surfaces results-not-logs. Standing guidance: [docs/workflow.md](docs/workflow.md#context-cost-discipline). The *cost* argument lands on the same place as the **Dumb zone** *quality* argument.

- **Token-usage tracking** — [spec 056](docs/specs/056-token-usage-tracking/spec.md) — `scripts/usage.py report <spec>` prints per-spec **orchestrator / subagent / combined** token totals (all *measured* per-turn from transcript `message.usage`; subagents summed from the nested `<session>/subagents/agent-*.jsonl` files) plus a ccusage-priced `$` estimate (store token counts, price via `npx ccusage` — never hand-roll rates, the [spec 055](docs/specs/055-context-cost-discipline/spec.md) analysis found hand-rolled Opus pricing ~3× high). Attribution **prefers an exact `.jig/spec-ref` marker** (stamped by `workflow.py transition … IN_PROGRESS`; working-tree-local, gitignored) and falls back to a dominant-spec-mention content heuristic, **flagging** heuristic-only sessions as lower-confidence. This *measures* the lever 055 *optimizes* (cost ≈ orchestrator context-size × turns).

- **Thin-orchestrator discipline** — [spec 057](docs/specs/057-thin-orchestrator/spec.md) — the data-driven follow-on to [spec 055](docs/specs/055-context-cost-discipline/spec.md): a 2026-06-03 deep-dive (25 sessions, 8,379 turns) confirmed cost is the two **Family-2** knobs — **turn count** (`cache_read` r=0.92) and **peak context** (r=0.96) — plus **output volume** (~22%, 5×-priced); cache-TTL/hit-rate tuning and model-downgrade were *falsified/minor* and rejected as levers. Three soft, non-blocking, measurable-via-056 mechanisms, one per knob: (01) **turn count** — `workflow.py session-plan <spec.md>` emits a stdout-only, pure-function per-slice dispatch plan (implement → compliance → craft → [arch iff `arch_review:true`] → reconcile → land) distinguishing **DELEGATE to [subagent]** vs **ORCHESTRATOR step** + naming real `{skill}`s, so the orchestrator dispatches-and-integrates rather than improvising turns; (02) **peak context** — `JIG_CONTEXT_COMPACT_PCT` (default 0.75) escalates the 055-02 `jig-context-check.sh` warn-nudge into an actionable compact/handoff prompt at a high band (band injected into `_growth_bands()`; once-per-band/re-arm machinery reused verbatim; never runs `/compact` — ADR-0011); (03) **output volume** — `docs/workflow.md` "Keep emitted output lean" + a "Return a tight envelope, not a transcript" convention in `agents/implementer.md`/`reviewer.md` (return-side sibling of 055-04). All soft/advisory; jig recommends, the user/harness acts.

- **Slice-claim on IN_PROGRESS** — [spec 049](docs/specs/049-slice-claim-on-in-progress/spec.md) / [ADR-0015](docs/decisions/adr-0015-worktree-aware-reservation.md) lineage (spec 028 reserve-on-main, one level up) — `workflow.py transition <slice> IN_PROGRESS` stamps frontmatter `claimed_by:` (current branch name, or `JIG_CLAIM_ID`) on a file-per-slice slice and **refuses a foreign still-IN_PROGRESS claim** (names the holder + points at `--release`); the status board renders it as `IN_PROGRESS (<claimed_by>)` (suffix, truncated >30 chars; 049-02). **The claim is LOCAL by default** (deviation from the spec's AC2/AC6 push-by-default — keeps "start a slice" offline-friendly); `--push` / `--pr` opt into reserving it on `origin/main` via a **uniform ephemeral detached-worktree** (collision-checked vs `git show origin/main:<path>`, pushed BY SHA from `project_dir`; race / protected-branch handling mirrors `workflow.py new`). Claim cleared on REVIEWED / back-transition; `--release --reason "<why>"` force-clears + logs a `## Release log`. Claims are frontmatter-only (prose-only slices refuse). Shared helper `_common/parsing.clear_frontmatter_field`. Inline-mirrors 028-01/003-03 (ADR-0002 **second** caller; extract on a third). Defense-in-depth like [ADR-0011](docs/decisions/adr-0011-spec-gate-model.md)/[ADR-0013](docs/decisions/adr-0013-security-floor-policy.md) — durable land-time collision backstop is out of scope (mirrors the deferred 051-03).

- **Solo→team re-detection** — [spec 050](docs/specs/050-solo-team-redetection/spec.md) — scaffold-init evaluates the team signal (≥2 mailmap-normalized git authors, monorepo-guarded) once at init, so a solo-scaffolded project that later grows never got nudged for `people.md`. Now `memory.py team-check` (memory-sync's final step) re-runs it and nudges [y]/[n]/[never] to bootstrap; `workflow.py stale` surfaces the same drift as a `category: team-context` row (read-only, **stays exit-0** — AC4 resolved to *intent*, the 015-03 informational contract kept). Opt-out = **tracked** `.jig/no-people-md`, written by **explicit `scaffold-init --solo` only** (auto-detected solo stays nudge-eligible). The team-signal logic + the `.jig/no-people-md` contract live in `skills/_common/team_signal.py` (ADR-0002 rule-of-three across scaffold-init / memory-sync / spec-workflow; `team_context_drift()` is the shared predicate). `--bootstrap` renders the real `people.md.template` (byte-identity to scaffold's render pinned by a cross-check test).
- **Vocabulary barrier / lexicon** — [spec 065](docs/specs/065-lower-vocabulary-barrier/spec.md) / [ADR-0021](docs/decisions/adr-0021-lexicon-home-and-overlay.md) (all 5 slices DONE) — jig explains its own jargon **on demand, off the hot path**. One canonical lexicon (`skills/_common/lexicon.json`, stdlib-only loader `_common/lexicon.py` merging the project `glossary.md` overlay, **project wins**) feeds four consumers: the `jig-memory-scan` hook (065-02, one-line defs just-in-time), the **`/jig:explain`** skill (065-03/05 — term + artifact + passage modes; precedence `path→artifact / key→term / else→passage`; ephemeral, judgment-only), and the **self-defining-vocabulary convention** (065-04 — soft/forward-only/**no gate**; a managed block in `docs/workflow.md` written by `scaffold()`+`copy_machinery()`, the latter widening copy-machinery's contract to `docs/` per ADR-0013's `.gitignore` precedent). Nothing here is injected into the always-loaded `CLAUDE.md` (respects 055/057).

## Session workflow

1. Check [docs/specs/README.md](docs/specs/README.md) for current status.
2. Pick up next `READY_FOR_IMPLEMENTATION` slice.
3. Spawn `implementer` subagent with the spec path.
4. After deliverable is on disk, run the post-implementation review — three passes: compliance via `jig:independent-review` (always), craft via `pr-review` (always), arch via `arch-review` (only when slice frontmatter has `arch_review: true`). See [docs/workflow.md](docs/workflow.md#post-implementation-review) and [skills/spec-workflow/SKILL.md](skills/spec-workflow/SKILL.md) § "After implementation" for the block rule.
5. Reconcile: update docs, write deviation log, run reconciliation review.
6. Run `/jig:memory-sync` to consolidate learnings.
7. Update spec status and status board.

## Constraints for agents working on this repo

- Do not modify [docs/conventions.md](docs/conventions.md) without explicit human approval.
- Reviewer subagent has read-only tools (Read, Glob, Grep). It cannot write to memory.
- [templates/CLAUDE.md.template](templates/CLAUDE.md.template) is the source template for scaffold-init. Do not confuse it with this file.
- Hook commands use `bash ${CLAUDE_PLUGIN_ROOT}/hooks/scripts/...` — never bare names.
- All hook scripts use Python 3 for JSON parsing — never jq.
- ADRs live at `docs/decisions/adr-NNNN-<slug>.md` (per ADR-0004). `adr.py` writes new ADRs there.
- Spec slices live in sibling files: `docs/specs/NNN-<slug>/slice-NN-<short>.md` (per spec 018). The `spec.md` is the overview; each slice is its own file.
- When a slice closes a spec, **compress** the spec's "Active specs" entry above per the rule in the slice template's `### Close-out (post-DONE)` section (per spec 025-01). Load-bearing per-slice invariants migrate to the status board Notes column, not to CLAUDE.md.
